# 开发经验与易回归点

本页提炼自真实历史需求和当前实现。引用的会话可在 [会话索引](history/OPENCODE-SESSIONS.md) 找到；完整文本位于本地归档。以下约束属于继承系统的工作方式，新游戏明确改规则时可以调整。

## 1. 先确认当前运行的是哪份代码

原项目从 `D:/OtherProject/TitanDemo/TitanDemo` 迁到 `TitanDemoGithub/TitanDemo`，现在又拷贝为 WordMerge。历史有“改 CSV 后数值没生效”的反馈，但可见记录没有证实单一根因。排查时确认终端 cwd、浏览器端口、Network 返回的 CSV 内容和实际装备 ID，再判断是否缓存或代码问题。不要直接把历史猜测写成根因。

数值只改 `public/config/` 下的正式表。桌面原始 CSV、`docs/history/original-design/`、旧 `dist/` 不参与 dev 配置加载；CSV 通常在页面挂载时读取，需要刷新才能验证新值。

## 2. UI 是覆盖层，避免改动战斗几何位置

2026-08-25 的多次返工涉及关闭 tab 后战斗画面下拉、底部挡住主角、下方点击没有攻击表现、列表无法滚动。现有 `.combat-section` 与 `.main-section` 使用绝对定位覆盖；`pointer-events` 让未被 UI 覆盖的区域仍能交互，列表用局部滚动容器。

提示文字、toast、装备低战力提醒不应出现时挤动布局。若改层级或容器，检查关闭 / 打开分页前后主角、怪物位置及滚动，而不只看单张静态图。

WordMerge 合成棋盘会根据可用区域自适应格子大小。物品说明和操作按钮必须预留稳定高度，长文案在内部滚动；只有 `min-height` 会让按钮换行撑高信息区，再通过 ResizeObserver 缩小棋盘。2026-09-30 已复现并修复点击野莓、饮水和体力物品时的缩放；检查时应比较未选中、不同棋子及使用后棋子消失的棋盘尺寸，并保留小屏棋盘滚动与窗口尺寸适配。2026-10-07 删除常驻提示条，实际操作反馈改为绝对定位浮层、4 秒消失，不占棋盘布局；顶部工具栏适配窄屏，订单固定 76px，不能再通过反馈内容撑缩棋盘。

需要随地图缩放的建筑气泡属于场景元素。只投影 DOM 锚点会让位置跟随、大小却固定；目前气泡由 Pixi 世界容器绘制，命中使用同一镜头的逆变换。透明无障碍镜像不能拦截指针，浏览器检查从真实画布轻点，覆盖大小缩放、图标位置、在气泡上开始的拖动 / 捏合 / pointercancel，以及取消与修复；不能只检查锚点移动。

来源：`ses_fcda519b0ffeP3IXijAy9EnW5x`、`ses_fbe166811ffef2WUQMYIERKsBr`。

## 3. 战斗暂停与组件生命周期有关

全屏二级页保持战斗组件挂载，通过状态抑制计时 / 攻击；死亡与出生完成回调推动怪物状态转换。如果改为卸载战斗组件，需要重新设计这些回调，否则可能卡在 `dying` 或 `spawning`。

Boss 主动撤退与超时失败语义不同：前者保留重试入口，后者重新走普通怪流程。修改时分别检查。

## 4. 数据驱动不等于删掉原有交互

装备表接入时，用户曾指出装备替换逻辑被删除，要求恢复。替换数据来源时列出需要保留的行为：选择、装备、更换、未拥有灰态、钻石购买、低战力提示。不能只做到列表显示新 CSV。

来源：`ses_fbe166811ffef2WUQMYIERKsBr`，消息 `msg_0474bc90f001E3Ccghg9su4WEe`。

## 5. 合成规则以最后一次确认及实际代码为准

生成器经历过“替换自身”“双击使用”“棋盘同链最高等级”“随机空格 / 仓库”“单击生成”的变化；当前规则见 [游戏基线](GAME-BASELINE.md)。生成器被禁止存仓库的最终变更在 2026-09-02。

锁格奖励通过 `rewardClaimed` 去重；订单只从解锁棋盘扣料；特殊棋子双击，生成器单击。不要用一次统一的 click / double-click 重构抹掉差异。

来源：`ses_fbe166811ffef2WUQMYIERKsBr` 和 `ses_f9f2af813ffezHw3mxTKYxZDxY`。

## 6. 拖拽视觉与数据提交分开

棋子原地状态由 reducer 管，拖动浮层跟随 Pointer Events 的坐标；无效落点只回弹。仓库拖拽会暂时隐藏仓库并在结束时重开，失败时物品仍应留在仓库。修改拖拽时要覆盖 cancel、无效落点和小屏触控，防止只在 mouseup 路径提交。

来源：合成会话中的拖拽反馈与仓库取回修订；实现位于 `MergeGameScreen.tsx`。

## 7. 共享资源与“保存”有明确边界

合成与战斗共享资源，订单奖励经 effect 接入全局。保持发奖去重，避免 React effect 重跑或返回页面导致重复获得物品。快照清理临时特效，不代表持久化到磁盘。

`5d66799` 增加的是合成页进出之间的内存快照。新游戏若要刷新后恢复，应另外设计版本号、配置兼容和保存时机，不能把 `persistMergeState` 名称当作已有存档证据。

## 8. 图标排查必须核实文件、symbol 和视口

当前图标配置拆成 `icon` / `iconName`。订单奖励复用装备目录图标，避免显示通用图标导致玩家不知道奖励了什么。新增 SVG 表同时检查组件白名单与 viewBox。

冰霜龙王历史会话曾把显示问题归因于 SVG symbol 的多行写法，`eb8fa36` 确实调整过对应资源；但“多行 SVG 会导致浏览器无法显示”未获充分验证，不作为通用经验。先检查 SVG 是否有效、ID 是否匹配、请求是否成功，以及实际渲染结果。

## 9. 沟通以实际交付为准

历史中用户多次要求继续完成、避免停在方案或“开始实现”的承诺。任务已明确时推进到可验证结果；进度消息写完成了什么和剩下什么。历史中的“忽略 vite 错误”是当时上下文，不能变成新工程隐瞒构建失败的规则。

## 10. 场景触屏打开弹层

- 地图在 `pointerup` 打开模态层时，浏览器随后生成的 `click` 可能落到新出现的圆盘按钮上，导致立即关闭或误下指令。指令盘在捕获阶段只接受从自身内部开始的指针手势，同时保留 `detail === 0` 的键盘激活；不能仅防止背景点击，因为原始点击也可能落到中央关闭按钮或指令按钮。
