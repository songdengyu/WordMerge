# 新游戏策划共识

更新：2026-09-30。来源为当前会话中的用户构想、选择、修订及逐轮确认。

这是设计记录，实际完成范围以 [新游戏改造记录](../NEW-GAME.md) 为准；当前已交付 M1 地图、M2 合成 / 精力 / 本机存档、M3 建造、M4 昼夜生存与守卫闭环、M5 首章剧情 / 探索 / 装扮原型。文中的“初调”表示已接受为验证起点，不是最终平衡值。M4 新增的伙伴、夜袭和救援参数另记于 [M4 实现记录](../implementation/M4-SURVIVAL-DEFENSE.md)；M5 人物对白、经验门槛、奖励与三天供需结果记于 [M5 实现记录](../implementation/M5-STORY-EXPLORATION-DECOR.md)。这些具体内容属于原型试玩假设，不自动视为策划定稿；目前服装仅改变外观，衣物保温仍是后续设计。新一轮未获确认的提案另放讨论稿。

## 1. 定位与循环

- 竖屏手机游戏，标签为二合、女性向、轻度生存、建造、剧情、装扮。
- 首个可玩版本已确认优先手机浏览器 H5；App 封装与其他发布平台后续评估。
- 日常生存与探索占主导；合成负责物资生产，建设改善生存，剧情与装扮提供长期目标。
- 现实荒野与人际悬疑题材。动物通过救助、喂养、建立信任成为伙伴，人类通过任务、关系和剧情招募。
- 主角不能主动攻击敌人，依靠建筑和伙伴自保；战斗保持简化数值与简洁表现，不要求动作操作。
- 主要循环：需求 → 合成 → 探索 / 建设 → 新生产来源、蓝图、人物与线索 → 营地成长。
- 地图重点奖励生成器、配方、蓝图、固有设施、一次性物资与剧情发现，不做独立的重复原料采集系统。
- 新区域逐步引入内容，底层支持配置扩展；不要求首版制作无限内容。

## 2. 时间与操作

- 每游戏日 24 小时默认映射为现实 20 分钟，可配置。06:00—19:00 为白天，其余为夜晚。
- 白天约 10 分 50 秒，夜晚约 9 分 10 秒；这是游戏时间，不绑定真实日历时段。
- 时间展示改为太阳 / 月亮与弧线进度，不再直接显示数字时分；保留第几天及黎明、上午、正午、黄昏、夜晚、深夜提示。地图右上角与合成页保持一致。
- 昼夜以场景光照表现：黎明微亮暖金、正午明亮、黄昏橘黄、夜晚整体变暗；自然流逝时平滑过渡。晴、多云、雨分别有光照、云影和降雨表现，界面文字与操作按钮保持可读。
- 主角可以随时进入合成并使用物资，包括在野外；打开合成不暂停世界、不提供隐身或免伤。
- 主角移动不再限制在格子中心：点击空地的具体位置，能直达就走直线，遇障碍自动绕行，沿途拐角平滑过渡；途中重新点击立即从当前位置改道。地形、建筑墙门与区域解锁仍约束通行，不能斜穿障碍或墙角。
- 敌人与主角、伙伴使用同一套平滑寻路和连续移动方式，追击实际位置并平滑转弯；保留各自移动速度、敌方门墙阻挡和区域动物的活动范围。区域常驻野生动物无目标时在出生点附近巡逻，到点短暂停留；靠近索敌后沿用原有攻击机制。
- 2026-10-07 修订：白天也刷新怪物，夜晚数量更多；从主角附近且当前镜头不可见的可达区域出现，再向主角移动。无合适位置时延后刷新，新的动态怪物在天亮时保留。出生时部分动物随机获得可驯服状态，头顶显示材料气泡，完成驯服后成为额外伙伴，不替换栗栗。当前中立接近、材料、概率、密度及容量初调见 [动态遭遇](../implementation/DYNAMIC-ENCOUNTERS.md)。
- 打开合成保留角色原来的地图行动；合成页持续显示日夜图标、角色行动、安全状态和重要预警。
- 剧情阅读与强制教程作为暂停例外；危险提示本身不暂停世界。
- 退出或切到后台后，昼夜、饥渴、敌人、施工等世界过程暂停；重新进入继续原时刻与过程。
- 精力自然恢复是离线暂停的明确例外，按真实经过时间恢复。
- 夜间可继续合成、照护、补给、室内装扮与人物互动，并应对持续营地袭击。

## 3. 生存属性与精力

- 原界面“体力”统一更名为“精力”，内部存档字段不改，自然恢复和超上限规则不变。
- 建造、修复、驯服、地块开放和资源清理每次开工扣 1 饱食度、1 水分；前往取消、缺料建单不扣作业消耗。原有随时间的下降保留。
- 主角实际移动累计每满 10 格扣 1 饱食度、1 水分，未满的距离跨行动和读档保留；斜线按实际长度计，救援传送不计入。
- 生命、饱食度、水分的常规上限为 100；生命小于等于 0 触发失败。
- 生命实际下降时在爱心图标上方显示红色扣血飘字，短暂上移并淡出；补血不显示扣血提示。
- 原“寒冷值”改称体感温度，0 极冷、50 适宜、100 过热，是归一化状态而非摄氏温度。
- 饱食度、水分小于 20，或体感温度小于 20 / 大于 80 时，持续损失生命。
- 饥饿、缺水、温度异常取最高一档环境伤害，不把三种伤害简单相加；敌人攻击伤害独立结算。
- 饱食度、水分在 40 附近提前预警；温度接近危险区时提示成因及应对方式。
- 天气、昼夜、住所、衣物影响温度的变化方向，状态逐渐变化，不因切天气直接跳到危险值。
- 首章晴、多云、雨；雪及明显过热环境在后续区域开放。早晨提供天气预告。
- 天气以小图标叠放在日月图标右上角。营地生存状态去掉底框、文字和数字，使用约原来两倍大小的图标：生命为红色爱心、饱食为胃、水分为蓝色水滴，以内部填充高度表示剩余量，接近零时仅保留彩色描边；体感温度使用白色外框、填充由下到上蓝—绿—红渐变的温度计。状态图标及伙伴爪印靠左依次紧凑排列。合成页沿用相同图形并采用紧凑尺寸。
- 初级完整住所能够应对首章常见天气；更严酷环境引出取暖、衣物和建筑升级。
- 图标不加额外的白色外沿或浅色光晕；温度计自身保留细白色边框与刻度，其他状态保留各自颜色的轮廓。
- 2026-10-08 修订：移除状态栏的伙伴爪印按钮及“照护与守卫”面板。伙伴操作通过场景动物材料气泡和伙伴指令盘进行，手记救助目标定位栗栗。
- 增加状态快捷补给：点击状态图标自动消耗对应资源，缺少资源时提示；达到扣血预警线时，右上角显示资源图标，有料为正常背景并可直接使用，缺料时图标背景变红、图标保留原色，可点击进入合成、生成补给订单。
- 当前已接入生命、饱食、水分，地图 / 合成 / 照护入口共用规则。每次使用一件棋盘或仓库中的可用道具，优先低阶，不消耗锁定或工程预留物品；满值时保留物资。饱食和水分在 ≤20 显示补给角标，生命沿用 ≤30 的低生命预警（持续扣血规则仍为饱食 / 水分 <20）。
- 补给订单按状态去重并保存；备好后点击订单消耗道具、恢复状态，不额外发放货币或物资。手动使用同类补给也会结束该状态订单，允许取消订单。
- 温度尚无对应消耗品，暖身 / 降温道具方案待确认；当前点击温度计显示住所保温及遮蔽降温提示，尚未接入温度资源角标与补给订单。
- 精力为 0 不直接伤害生命；仍可移动、整理、存取、吃喝和对话。
- 精力允许持续游玩，主要约束短时间大量生产，不以强制离线等待为主要目标。
- 自然恢复到 100 停止；道具增加可超过 100，超出值保留并正常消耗。
- 当前精力大于或等于 100 时不积累自然恢复额度，降到 100 以下才重新恢复。
- 例如 90 + 道具 50 = 140；140 离线一小时仍为 140，消耗到 99 后重新自然恢复。
- 普通食物主要补饱食，部分料理可补精力；高效精力品可通过任务和探索奖励获得。
- 稳定生存供给不能只依赖一次性奖励；避免可瞬间循环、稳定净赚大量精力的生产链。

### 待试玩初调值

| 参数 | 起点 |
|---|---|
| 普通生成器使用 | 消耗 1 点精力 |
| 精力自然恢复 | 每现实 10 秒 1 点，满值时不累计 |
| 普通探索作业 | 按事件消耗少量精力，具体表待定 |
| 普通建设 | 材料与施工时间为主要成本，暂不额外扣精力 |
| 手动合成、整理、存取、移动、使用物品、对话 | 不扣精力 |
| 普通状态每游戏日饱食消耗 | 约 60 点 |
| 普通状态每游戏日水分消耗 | 约 80 点 |
| 普通食物 / 饮水恢复 | 对应属性约 40 点 |
| 环境危险伤害 | 每现实 5 秒扣 1 点生命作为起点 |

一个在线游戏日理论最多自然恢复 120 点精力，满值溢出的时间不算实际所得。平衡检查必须覆盖连续第二、第三个游戏日，不能只依赖开局 100 点。

## 4. 棋盘、仓库与订单

- 复用现有二合棋盘、生成器、锁格、拖拽与仓库操作，表结构尽量延续。
- 当前任务订单置于订单列表首位，使用绿色选中边框，左上角小图标区分建造、修复、补给、驯服与委托。地图缺料需求自动选中对应订单，点击其他订单可切换；完成或取消后选中剩余首单。
- 不新增背包。物品存在于棋盘或仓库；存取只改变位置，不复制物品。
- 在地图任意位置可访问合成和仓库；其中可用道具可直接使用，不要求回营或出发前装包。
- 生成优先棋盘空格，棋盘满时沿用入仓逻辑；两处都满不扣生成费用。
- 生成器持续提供生产能力，不作普通消耗品交付，仍不能存仓库。
- 合成在棋盘进行；仓库物品可直接使用，或取回棋盘继续合成。
- 建设、修复、任务统一统计棋盘与仓库中的可用物资；半锁、全锁或已预留物品不能重复交付。
- 基础生存物资需有稳定来源，随机性更多用于额外发现和稀有物品。
- 日常补给、早期建设使用低中阶短链，高阶产物服务重要升级和章节目标。
- 现有仓库初始 6 格需要按新游戏开放的合成链重新评估，容量尚未最终确定。
- 两处都满时允许整理、使用，或确认丢弃普通棋子；保护关键生成器与剧情必需品。

### 地图建造订单

1. 材料需求直接显示在地图建筑上方的部件气泡，不再打开材料详情子界面。气泡是场景元素，位置、大小、材料图标、数量及点击范围随地图一起移动和缩放，不使用固定屏幕尺寸。
2. 材料不足时气泡保持普通颜色，点击进入合成并建立绑定该部件的订单，显示持有 / 需求数量。
3. 同一部件重复点击打开同一张订单；接单不扣材料。
4. 条件满足时气泡变绿，点击直接预留材料并自动前往施工；也保留合成页领取工程的入口。
5. 开工前取消或无法到达，释放预留；正式开工时扣除材料。
6. 开工后不可中断，完工才发建设经验。

订单领取在这里是提交物资与发起建设，不额外复制发放相同材料。未领取前多个订单可以显示相同库存；领取预留后其他订单立即更新。

2026-10-06 建筑粒度修订：图纸中的围墙、地板 / 地基、屋顶仍按整组建造，一次施工完成该组；受击则按单段围墙、单格地板 / 屋顶独立扣耐久。损坏后逐件修复，每件有自己的材料气泡、订单与预留，修复仍为 2 秒且不重发经验。破墙只形成局部缺口，修复只恢复目标部件；独立修复期间保护该小部件和主角，其他部件仍会受击。

墙体耐久后续确定为：小木屋单段墙 20，大屋单段墙 30。按野猪每击 4 点计算，从满耐久分别需要 5 次与 8 次攻击击破。

屋内地板可直接点击移动，遵守原门墙寻路。移除独立“进入 / 回家”按钮，人物通过地板点击进入屋内或在屋内走动；保留床边休养功能。

保留剧情 / 居民订单的交付和奖励能力，完成结果可进入对话、推进任务或获得奖励。首版优先闭合建造、剧情两类。

## 5. 建筑与施工保护

- 整栋蓝图自由选址、选择朝向，按预设地基、外墙、门、屋顶、内部设施分部分建设。
- 分开表示“可使用”和“完全建成”；先形成基本庇护，再逐步完善。
- 建筑生活条件与防御条件分开展示：避雨、温暖、休养，以及入口关闭、受损、缺口。
- 外墙和关闭的门负责阻挡与承伤；屋顶负责避雨、保温；床铺支持休养；取暖设施应对更冷环境。
- 建筑受损后可修复，重要投入与装饰成果保留，修复成本低于重建。
- 装饰不混入主要防御部件，避免常规夜袭反复损毁审美投入。
- 同时只执行一项主角地图作业，后续施工可排队；开工前的等待与排队可取消。
- 前往施工地点仍正常受伤；到达并实际开工才获得保护。
- 建造与修复统一为 2 秒活跃模拟时间，不含前往工作位的时间；后台仍暂停。
- 开工后不可主动或被动中断，主角和当前施工 / 修复部件均无敌，其他部件正常受损。
- 施工期间饥渴、温度与世界照常变化，但主角免受所有生命伤害；完工后恢复正常结算，不追补施工期间伤害。
- 使用道具不需要取消施工；退出后保存施工状态，世界暂停，返回继续。
- 只对实际缺失或受损部件开工，不允许反复修复满耐久部件免费获得保护。
- 经验主要来自首次建设、升级、探索和章节成果；不通过重复修复、拆建同一进度刷经验。

### 地块开放（2026-09-30 修订）

- 移除“营地地图”页及区域列表，开放入口直接放在场景中。
- 每个未开放地块四边各有一个指示牌候选位置，仅与已解锁地块接壤的一侧显示，其他侧隐藏；相邻地块开放后自动显示对应牌子。牌子显示已有 / 所需建筑经验。
- 经验满足且该侧可接近时，点击后主角自动前往指示牌；在已开放的相邻地块一侧作业，不能穿过未开放地形。经验不足或路线不可达时提示原因。
- 到达后计时 2 秒再开放整片地块，四块牌子同时消失。经验仅为门槛，不扣除，也不因开放额外发经验；取消旧区域解锁的剧情前置，剧情仍按章节顺序推进。
- 开放作业与建设 / 驯服互斥；前往途中可取消，开工后不可中断且主角免伤。后台暂停，刷新恢复原进度。
- 溪谷深处放置 3 只常驻野猪，主角靠近时攻击；这类区域动物天亮不撤走，活动保持在所属区域。伙伴可应战，主角仍不能主动攻击。
- 静谧林地预置一座大房子的地基，沿用地图材料气泡和 2 秒分部件建造。当前占地初定 5×4，材料、耐久和经验为原型数值；区域解锁时发现，旧档兼容补入。

## 6. 夜袭与伙伴

- 夜间敌人明确以营地为目标，不依靠躲藏让整场袭击消失；躲进住所让建筑承担伤害。
- 敌人持续补充直到天亮，清理当前敌人只能争取短暂间隔，不提前结束整个夜晚。
- 场上同时存在的敌人数有配置上限，补充有间隔，不无限堆积。
- 敌人在配置的外部入口出现，不生成于已封闭住所内部。
- 天亮停止补充，正在袭击的敌人撤离，恢复日间状态。
- 敌人不能取消施工或伤害受保护对象；优先选择其他相关可攻击目标，无有效目标则等待并计入场上上限。
- 伙伴按驻守指令自动应敌，玩家可手动指定目标；主角不能主动攻击。
- 伙伴与敌人靠近后隐藏双方模型，原地播放 2 秒打斗烟尘。后台按双方当前生命、攻击力与攻击间隔模拟到一方倒下，烟尘结束后统一应用剩余生命；胜者庆祝、败者倒地。主角受击仍按原即时扣血方式。
- 交战锁定一对单位，演出期间不能改令或治疗；同拍攻击同时生效，允许双方同时倒下。天亮让已开打的一对完成结算，其余夜袭敌人照常撤离。
- 伙伴战败受伤、失去战斗能力并需要救治，不永久死亡，不丢成长和外观。
- 第一位伙伴通过救助等非战斗前置取得，避免必须先赢一场需要伙伴的战斗。
- 可驯服动物头顶显示场景内材料气泡，随地图缩放；物资足够时变绿，点击自动前往，缺料则进入合成并生成去重订单。到达后驯服统一暂定 2 秒。
- 栗栗的驯服材料为 1 份 3 级野餐餐盒（213），由野莓 → 果酱 → 野餐餐盒合成；替代原先的 1 份野莓。
- 驯服沿用施工流程：预留棋盘 / 仓库真实物品，到达工作位才扣料，途中可取消；开始后不可中断，主角免伤。白天才能开始，途中入夜释放预留，已经开始则继续完成。
- 点击已驯服的伙伴，屏幕中央弹出半透明指令圆盘，中心显示名字，上方移动、左侧驻守、右侧跟随、下方治疗。圆盘不暂停世界；驻守仍以主角当前位置为准。
- “移动”替代主动休养：点击后进入持续操控伙伴模式，地图轻点给伙伴指定目的地，可连续改点；屏幕显示“取消操控”，点击后恢复主角地图操作，不撤销伙伴已经收到的移动指令。伙伴到达后在新位置驻守，途中仍可被敌人拦截交战。主动休养与对应自动回血移除，药品治疗及受伤恢复计时保留。
- 主角移动只显示终点，不显示路径。伙伴复用主角的平滑移动逻辑，支持格内落点、直线优先、绕障圆滑和途中改道；移动速度仍由各自配置决定。
- 正常准备下应允许玩家连续合成一段时间再检查营地，先按两三分钟的观察间隔验证。
- 日常补给与修复先按约当天稳定生产能力三分之一的维护预算验证，其余应可用于发展；挑战夜袭另有明确预警。
- 施工免伤、修复材料、施工耗时与恢复耐久联合平衡。
- 具体敌人目标优先级、通路、交战规则和失败结算为当前讨论主题，尚未全部锁定。

## 7. 剧情、装扮与失败边界

- 旧森林营地、家人往事、居民各有立场作为主线工作方向；具体人物、章节和最终谜底待细化。
- 前期困境恢复道路与通信后，主角可以主动选择留下重建和调查，不永久依赖无法联系外界。
- 剧情通过生活问题、生产任务、建筑发现和对话推进，减少生存学习成本。
- 选项优先影响态度、信息、入住时机与关系事件；关键居民有后续招募机会，重要不可逆后果需提示。
- 装扮较早进入循环，衣物外观与温度功能尽量可兼顾。
- 失败允许损失部分普通物资，保留主要成长、关键来源、蓝图、剧情进度与装扮；精确损失规则待讨论。
- 已确认只有主角生命归零才触发失败结算。住所被攻破不立即判负，主角仍可撤离、指挥伙伴、使用物资或寻找合法施工机会自救，营地仍会继续受损。
- 正式存档与后台恢复是首个可玩版本的基础能力；M2 已具备本机存档与恢复，后续玩法继续扩展版本化快照。

## 8. 已被后续选择替代的建议

| 旧提案 | 当前规则 |
|---|---|
| 合成时暂停世界 | 在线合成时世界继续 |
| 回营才能生产、出发前装补给包 | 随时合成与使用仓库，无背包系统 |
| 全部过程离线暂停 | 世界暂停，精力按真实时间恢复 |
| 主动休息是主要精力恢复手段 | 自然随时间恢复及道具补充 |
| 精力硬上限 100 | 自然恢复上限 100，道具可突破 |
| 已开工可中止、保留进度后续建 | 开工后不可中断，主角和当前部件无敌 |
| 所有敌人巡游发现后才袭击 | 夜袭敌人明确攻击营地；区域野生动物巡逻、靠近才索敌 |
| 达成掠夺目标或受挫即撤 | 被击退或天亮才结束当前敌人威胁 |
| 每晚有限批次、可提前清场 | 持续补充到天亮，但有场上数量上限 |
| 伙伴败者死亡消失 | 受伤待救治，保留成长与外观 |

## 10. 经济与地图资源清理

- 增加金币、钻石显示和商店入口，购买建筑图纸、摆件、衣裳。图纸永久解锁放置权限，建造另需材料；装扮沿用既有装备和摆放规则。
- 已开放地图的树木、石头、旧营火、路标可清理。点击显示所需工具气泡；足料变绿、点击前往，缺料转合成并生成当前订单。树木使用斧头，石头使用石镐，两种工具均加入二合链。
- 前往时预留工具，到相邻工作位才消耗；开工 2 秒且不可中断，主角免伤，完成移除场景物体并奖励金币、钻石及合成材料。资源清理结果存档，刷新不重生或重复发奖。
- 新增工具箱可在商店免费领取一次，需棋盘空位；产出零件后两个相同零件合成工具。清理一次消耗一件工具。
- 已拥有图纸和人物皮肤不重复扣费；摆件允许重复购买、每次获得 1 件，剧情仍可赠送同款 1 件。满仓清理材料保留待领取，商店领取时检查空间，货币不重复结算。
- 独立“装饰”系统管理人物皮肤、摆件库存和已摆放实例，原手记装扮页移除。皮肤可反复装备；摆件无拥有数量或同款摆放数量上限，确认摆放库存减 1，取消不扣、移动不扣、逐件收回库存加 1。摆放仍需空闲的已建地板，一格一件。
- 本轮价格、掉落和具体商品属于可调原型配置，见 [经济实现记录](../implementation/ECONOMY-RESOURCE-SHOP.md)；资源耗尽后的长期货币供给与商业化不在本轮定稿范围。
