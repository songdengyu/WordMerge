# 本轮讨论稿：夜袭、伙伴与失败结算

更新：2026-09-29。状态：本轮建议，尚未整体获得用户确认。前几轮已确认约束见 [CORE-RULES.md](CORE-RULES.md)。

本稿继续细化游戏行为，不代表已经实施代码。用户在本轮已明确选择“仅主角生命归零才结算失败”，此项已同步到共识文档；其余本轮新增细则仍为建议。

## 1. 既有约束

- 敌人明确袭击营地，持续补充到天亮；有补充间隔与场上数量上限，不允许提前永久清场。
- 主角不能攻击，伙伴自动驻守且可手动指定目标。
- 主角可以随时合成、使用棋盘和仓库物资；合成期间世界继续运行。
- 施工开始后不可中断，主角与当前部件无敌；前往施工时无保护，其他部件正常受损。
- 伙伴战败受伤不永久死亡；普通物资可有损失，核心成长与装扮保留。

## 2. 敌人一次行动的流程

外部入口出现 → 接近营地 → 选择可交战目标 / 通路 → 战斗或破坏 → 目标变化后重新判断 → 被击退或天亮撤离。

### 营地目标

先为每个夜袭入口配置所袭击的营地区域与默认目标建筑，通常为已设置的主住所；首版不自动把地图上每一处蓝图都算成新的袭击中心。

默认攻击型敌人的局部目标优先级建议如下：

1. 已经接战、在范围内且有效的伙伴，优先维持当前战斗。
2. 附近可到达的驻守伙伴或暴露主角，按配置的索敌规则接战。
3. 前往营地目标；现有通路可用则沿通路进入。
4. 路被封闭时，攻击通向目标的就近可达门墙部件。
5. 原目标进入施工保护时改选其他相关目标；不存在有效目标时等待，继续计入数量上限。

目标有效时不每帧改选最近对象，避免来回抖动。失去主角目标后返回营地任务，不因玩家跑远而结束袭击。倒地伙伴、装饰、尚未解锁区域中的对象不进入普通攻击目标列表。

后续可为觅食动物、偷盗者增加不同目标偏好；首版先做一套可理解的基础规则。

## 3. 通路与破损

- 地形、水域和不可通行结构形成通路约束，单位不能穿墙攻击或移动。
- 优先使用现有缺口，不一律无视开口去敲墙；没有通路时才破坏门墙。首版不做计算全营地最廉价拆墙路线的高级策略。
- 门墙耐久为 0 时进入破损状态并失去阻挡，保留位置、建筑归属及修复入口，不删除整个建筑。
- 屋顶受损影响生活条件；地毯、花盆、墙饰等不成为普通夜袭的破坏目标。
- 新部件未完工前不提供完整阻挡；已经破损的部件开始修复时不会立即重新封路，完工才恢复阻挡。
- 因此，施工免伤保护当前主角与部件，不保护整间屋，也不立即把缺口封闭。
- 完工时处理通路、单位占位及建筑状态，不吞掉单位或让主角永久困在不可通行位置。
- 友方正常通行时门自动开合，首版不把开门动画的一瞬作为敌人钻入判定；明确保持开启或门被破坏时才开放敌方通路。

## 4. 伙伴指令与交战

### 首版行为

| 指令 | 建议行为 |
|---|---|
| 跟随 | 跟随主角，对附近威胁自动应敌；不会自动承担远处营地防御 |
| 驻守 | 在指定位置附近拦截可达敌人，追击有范围限制，结束后回驻守位置 |
| 指定攻击 | 玩家明确指定敌人，伙伴前往交战，目标失效后恢复原行为 |
| 休养 | 留在安置处恢复，不主动接战 |

驻守应显示覆盖范围。伙伴不跨未解锁区域，不隔墙攻击；无法到达目标时提示原因。手动指定攻击可以覆盖普通驻守目标选择，但不忽略通路。巡逻作为后续可增加的行为，不要求首版同时完成。

### 简化战斗

- 仍是攻击力与生命的简单加减。接近后自动交战，播放统一打斗特效、生命变化与胜败动作，不增加走位闪避、技能连招等操作。
- 建议固定攻击间隔、按同一时刻的状态计算该拍伤害，再一起应用，避免先处理的对象在相同条件下永远占优。
- 每个单位当前只攻击一个目标，允许多个单位支援同一场交战。敌人不足时不让多余伙伴围着无效目标等待。
- 交战不冻结全图，其他敌人仍会攻击建筑；不能靠无限延长一场战斗暂停夜袭。
- 同拍双方归零时双方退出战斗：敌人退场，伙伴受伤；不强行指定一方获胜。
- 一场交战后的剩余生命保留，不在换目标时自动满血。具体攻击间隔与属性数值待测。

### 伙伴战败

建议自动退出战斗并进入受伤待救治状态，保留等级、外观与关系；敌人不继续攻击倒下伙伴。通过药品与休养恢复，普通回血与倒下后的恢复参战分开，避免一瓶普通药不断瞬间复活顶住所有敌人。

退场、安置表现、重伤恢复耗时及药品需求还需在伙伴专题细化。首章数值应支持正常驻守一段时间，不能要求玩家每几秒手动给药。

## 5. 突破与失败

### 已确认：住所突破不立即判负

门墙被突破后警报升级，敌人可以通过缺口进入。主角若仍有生命，可以移动至其他庇护位置、指挥伙伴、使用物资，或前往有真实材料需求的部件开始施工。路上不无敌，实际开工才受保护。

建筑部件破损不立即删除装饰、清空进度或强制判负。只有主角生命归零才进入失败结算，不把门破损或住所失守作为额外强制失败条件。

### 主角生命归零后的建议

暂停世界并显示一次失败结算，保留阅读时间。确认接受救援后进入次日清晨的恢复状态，本夜敌人结束。该过程是明确的失败转场，不视为离线经过时间。

- 保护蓝图、生成器、关键剧情道具、唯一解锁物、伙伴、经验、装扮与建筑已完成进度。
- 只对当时拥有且允许损失的普通物品应用一次损失；数量上限与高阶物品保护待定。
- 为适配二合的指数成本，不能按所有棋子均等概率抽取损失，避免失去一枚高阶棋子相当于数百次生产。
- 预留而未开工的任务释放预留并返回待准备状态，不复制或重复扣除物品；已开工工程不得被此转场取消或提前免费完成。
- 有尚在进行的无敌施工时，主角不会因伤害进入生命归零失败；其他特殊转场需先定义与不可中断施工的兼容规则。
- 进入次日不是自动完成其他等待中的工程，不额外结算一整夜的饥渴、敌伤或经验。
- 归零的失败状态立即存档，重新打开不能恢复到失败前并绕过结算。
- 若没有可损失普通物资，损失为零，不扣成负数，也不改扣关键来源。
- 救援后的初始状态和基础应急物资需足够重新进入生产循环，但不额外提供可反复死亡刷取的稀有奖励或经验。

### 防止两次扣同一笔损失

首版建议普通夜袭以战斗和结构受损为主，不再同时从共享棋盘 / 仓库实时随机偷取物品。普通物资直接损失集中在失败结算，修复消耗由玩家主动选择。后续若增加偷盗型敌人，必须与单夜损失上限统一计算。

## 6. 持续夜袭的压力控制

- 从区域 / 章节配置取敌人强度、补充间隔、场上上限、入口与预告。首版不按存活天数无上限增强，允许玩家停留经营和装扮。
- 不因玩家战斗效率高就自动无限加快刷怪；满数量上限时不积攒待爆发的刷怪欠账。
- 合成界面显示当前敌人数、关键部件状态、伙伴状态与夜晚剩余时间，突出正在失守的部分，不要求每拍切回地图。
- 平衡测试目标沿用前轮：正常准备允许连续合成两三分钟后检查；日常补给和修复约稳定产能三分之一作为起点。
- 天亮先停止刷怪与新增攻击，再处理撤离；未击败的撤离敌人不发击败奖励，已确认战胜的敌人奖励只发一次。

## 7. 讨论与验证案例

| 场景 | 应检查的结果 |
|---|---|
| 有缺口和完整门并存 | 敌人能使用缺口，不固定攻击门 |
| 目标部件开工进入保护 | 主角 / 部件无伤，其他目标仍受威胁；敌人不撤销施工 |
| 破损门开始修复 | 工程受保护，但缺口在完工前仍存在 |
| 玩家在合成中，驻守伙伴打赢一场 | 伙伴返回职责范围，保留剩余生命；世界继续 |
| 伙伴追击超出驻守范围 | 自动返回，不被无限引走 |
| 门破但主角存活 | 不立即结算失败，主角仍可自救，营地继续承受威胁 |
| 主角归零并重开应用 | 仍进入同一次失败结算，不多扣物资、不绕过结算 |
| 身上只有一枚高阶棋子或关键生成器 | 不能因均等随机损失破坏核心成长，空损失也有效 |
| 场上敌人满额后逐步被清理 | 按正常间隔补充，不瞬间补出整夜欠账 |
| 天亮与攻击在同一步到达 | 边界优先级固定，不出现提示天亮后仍持续攻击 |

本轮讨论确认后，再细化建筑、敌人、伙伴的第一组数值，以及首个可玩版本的场景和验收流程。
