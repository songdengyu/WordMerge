## 已确认范围

以本目录的 TitanDemo 拷贝工程为基础开发二合、女性向、轻度生存、建造、剧情与装扮的竖屏手机游戏。迁移准备与技术方案已完成，用户已授权逐阶段开发，当前已交付 M1 地图、M2 合成 / 体力 / 本机存档、M3 建造、M4 昼夜生存与守卫闭环、M5 首章剧情 / 探索 / 装扮原型。首个可玩版本优先手机浏览器 H5。

已确认设计及待试玩数值统一记录在 [CORE-RULES.md](design/CORE-RULES.md)。本页作为状态与阅读入口，不重复维护全部规则。

当前技术入口：[TECHNICAL-PLAN.md](TECHNICAL-PLAN.md)，给出 React + PixiJS + 独立 TypeScript Runtime + IndexedDB 的实施基线、配置方式、分阶段交付与测试目标。PixiJS、idb 与测试依赖已安装，实际范围见阶段记录。

[夜袭、伙伴与失败结算](design/NIGHT-DEFENSE-DISCUSSION.md) 保留为玩法工作稿，具体平衡参数与尚未确认细节继续在专题内修订。
