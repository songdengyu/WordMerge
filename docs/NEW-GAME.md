# WordMerge 新游戏改造记录

更新日期：2026-09-30。

## 已确认范围

以本目录的 TitanDemo 拷贝工程为基础开发二合、女性向、轻度生存、建造、剧情与装扮的竖屏手机游戏。迁移准备与技术方案已完成，用户已授权逐阶段开发，当前已交付 M1 地图、M2 合成 / 体力 / 本机存档、M3 建造闭环。首个可玩版本优先手机浏览器 H5。

已确认设计及待试玩数值统一记录在 [CORE-RULES.md](design/CORE-RULES.md)。本页作为状态与阅读入口，不重复维护全部规则。

当前技术入口：[TECHNICAL-PLAN.md](TECHNICAL-PLAN.md)，给出 React + PixiJS + 独立 TypeScript Runtime + IndexedDB 的实施基线、配置方式、分阶段交付与测试目标。PixiJS、idb 与测试依赖已安装，实际范围见阶段记录。

[夜袭、伙伴与失败结算](design/NIGHT-DEFENSE-DISCUSSION.md) 保留为玩法工作稿，具体平衡参数与尚未确认细节继续在专题内修订。

以下区分已确认方向与仍需讨论的内容：

| 决策 | 当前状态 |
|---|---|
| 正式名称、具体美术风格 | 待定，WordMerge 仅为工程名；已确定竖屏、女性向、现实荒野人际悬疑 |
| 首个版本平台 | 已确认手机浏览器 H5；本轮技术方案采用本地单机，App 封装与后端后续评估 |

| 时间 | 一游戏日默认 20 分钟；合成时世界继续，离线世界暂停；体力按真实时间恢复 |
| 建造 | 整栋蓝图、分部件建设；订单备料后自动前往施工；开工不可中断且主角与当前部件无敌 |
| 夜间 | 敌人明确袭击营地，持续补充到天亮；伙伴驻守，主角不能主动攻击 |
| 失败与守卫细则 | 已确认仅主角生命归零才结算失败；其他目标选择、通路、伙伴应战与结算细则仍在讨论 |

| 首个可玩版本 | 技术方案以少量地块、一种木屋、一位伙伴、两类敌人与基础生产构成闭环；完整首发内容另定 |
