# 昼夜动态遭遇与野生伙伴

日期：2026-10-07。

## 当前行为

- 白天和夜晚都会刷新灰狼 / 野猪；夜晚刷新更快、在场上限更高。动态遭遇在天亮时保留；旧存档中没有 `roaming` 标记的原夜袭单位仍走旧撤离规则，撤离不发奖励。溪谷原有 3 只常驻野猪的巡逻、区域边界不变。
- 刷新位置围绕主角当前连续坐标选取，限定已开放、可通行的地面，避开建筑占地和其他动物，且与主角保持距离。使用友方门规则验证连通性，敌人实际行走仍受敌方墙门规则限制。
- CampScene 提供当前镜头可见性（含动物和头顶气泡的边缘余量），Runtime 负责选点与生成。拖动、缩放镜头立即影响排除范围。没有合适的不可见位置时延后重试，不在屏幕中强行生成；无渲染器的规则模拟仅使用距离 / 地形 / 连通性约束。
- 普通动态怪物向主角当前位置寻路，白天也会攻击；遇到封闭住所仍沿用破坏独立墙门段的逻辑。主角即时受击与开工保护不变。
- 出生时随机确定是否可驯服，存档后不重抽。可驯服动物初始中立，接近主角后停留；忍耐耗尽前不攻击，也不被己方自动选为敌人。2026-10-08 新增警觉忍耐规则，耗尽后永久转为普通敌对动物。

## 驯服与伙伴操作

- 可驯服怪物与主角距离不超过 `ENCOUNTERS.alertRange` 时开始警觉，模型头顶材料气泡旁显示红色生气符号；累计 `ENCOUNTERS.patienceSeconds` 秒后，永久设置 `tameable = false`，移除驯服气泡并进入原敌对索敌 / 攻击逻辑。动物主动靠近也按同一距离规则判断，仅主角触发，伙伴不触发。栗栗是首章救助角色，不参与此计时。
- 当前按“离开范围重置”实现：耗尽前退出范围会解除警觉、清零计时；耗尽后离开、天亮或刷新都不恢复驯服资格。合成期间继续计时，后台 / 剧情等世界暂停时不计时。计时保存于可选 `Enemy.alertSeconds`，旧档缺省为未警觉，不清档。
- 前往驯服途中仍消耗忍耐；耗尽时清除该动物的订单、释放预留且不扣材料，停止主角的对应前往路线。已开工的 2 秒驯服保持不可中断规则，目标解除警觉并暂停忍耐直至完成；其他动物照常判断距离。
- 复用场景材料气泡：缺料进入合成并建立绑定动物实例的订单；有料预留实际棋子、主角自动前往，精确到达才扣料并消耗 1 饱食度 / 1 水分。
- 已安排前往的目标停留等待，取消前往释放物资；开工后不可打断、主角免伤，2 秒完成。新动态动物昼夜都能驯服，栗栗保留原白天救助规则。
- 完成后将该敌人实例转为新增伙伴，保留物种、位置和当前生命，不替换栗栗、不发击败奖励。新伙伴默认跟随，可在指令盘切换移动 / 驻守 / 跟随 / 治疗。
- 多只动物靠近时优先点中离触点最近的模型；圆盘上方可切换伙伴，避免完全重叠时无法选中。指定移动和取消操控仍沿用主角 / 栗栗的连续导航与交互。
- 操控伙伴移动时，优先检测主角及其他已驯服、未交战伙伴的模型点击；点击其他伙伴退出当前操控并打开它的指令盘，点击主角退出操控并定位镜头。命中使用当前显示位置，重叠时按离模型中心的距离选择；仅切换临时 UI 状态，不派发停止 / 驻守命令，原移动继续完成。
- 野猪 / 灰狼伙伴使用对应物种的生命、攻击、攻击间隔和移动速度；栗栗数值保持原样。药品、倒下与恢复流程复用已有规则。
- 现有战斗演出仍保留一个交战槽，使用伙伴实例 ID 绑定交战双方；其他伙伴继续移动和选敌，待交战槽空闲再发起下一对战斗。烟尘 / 结算 / 胜负动作仍为 2 秒 / 原子提交 / 1 秒。

## 状态、保存和实现入口

- `Enemy.roaming / tameable` 保存来源和出生随机结果；`SurvivalState.recruits` 保存新增伙伴，旧档缺省按空列表读取。
- 栗栗继续位于 `survival.companion`，保持首章故事、旧档与旧命令兼容。新增伙伴沿用敌人唯一实例 ID，敌人和伙伴列表间不得重复。
- `taming.targetId` 绑定动态动物，缺省表示栗栗；预留仍使用单个驯服订单槽。合成订单交付、气泡、Runtime 均传递同一 ID。
- `duel.companionId` 缺省表示栗栗；读档按物种重新核算战斗结果，校验实际伙伴和敌人的锁定位置 / 生命 / 冷却。救援先结算已有交战，再清除动态野生动物及失效驯服订单，保留所有已招募伙伴和伤势。
- 保持 schema 4 和原内容指纹，不清档。新增状态有显式校验，旧档不会因为缺少 `recruits` 而失败。镜头和当前选中伙伴属于临时界面状态，不写存档。
- 多伙伴帧间插值复用按实例 ID 保存的上一模拟步位置；移动气泡只更新位置，不因动物行走不断重建 SVG 图形。
