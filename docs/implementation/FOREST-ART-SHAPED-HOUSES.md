# 绘本森林与异形户型（2026-10-09）

## 范围与表现

保留格子地形、连续移动、四向旋转和现有游戏规则。场景继续使用 Pixi 图形，不新增贴图下载或自由角度摆放。

- 地面使用连续底色，第二遍绘制草叶、小花、碎石、水纹与相邻地形过渡；阻挡仍来自原地图。场景细节在地块更新时重建，动画不持有游戏状态。
- 树木使用非对称层叠树冠，自然物件由 ID 派生稳定尺寸和外观变体；`objectAppearance` 同时供绘制、命中范围和资源气泡定位使用，树干原点不移动。
- 地板、屋顶去除逐格亮色外框，外围保留收边。墙体增加拱窗、窗台与花饰；墙、床、家具和角色按场景深度排序，地毯保留地面层。门动画、进屋 / 摆放隐藏屋顶、分段损坏仍保留。
- 地毯为椭圆编织外观，摆件补充落地阴影与细节；未改库存、物品 ID、可摆放位置或数值。昼夜、天气和照明继续应用到场景。

## 异形图纸

`Blueprint.cells` 为可选本地格坐标列表；`blueprintCells` 对未设置的旧图纸返回原矩形，保持原来的顺序。宽高表示外包范围，不是实际地板面积。

| 图纸 / 商店 ID | 占格 | 门 | 定价 / 数值来源 |
|---|---|---|---|
| 森语转角屋 `forest-corner` / `corner-blueprint` | 4×4 去掉右下 2×2，12 格 | `(1,3)` 向南 | 320 金币；暖杉小筑材料、耐久、经验 |
| 花庭小院 `flower-court` / `court-blueprint` | 5×4 去掉 `(2,2)`、`(2,3)`，18 格 | `(2,1)` 朝凹口 | 45 钻石；蔷薇庄园材料、耐久、经验 |

床在 `(0,1)`；其余初建工作位为门内侧，施工与修复仍为 2 秒。墙由实际占格的外围四邻边生成并排除门边，内部不生成墙。占格必须唯一、在外包范围内且四向连通，工作位位于真实地板内，门墙连接内格与外格。

`footprint`、地板 / 屋顶部件、放置与保存校验、室内与家具判定共用实际占格；导航继续由真实墙门边派生。凹口是可通行室外，不能放屋内摆件。预览保留格子辅助精确摆放。

异形屋顶仅绘制真实地板格；按距外围边的距离计算共享顶点高度，拼接不同翼部，檐口与墙顶对齐，凹口不生成顶面。损坏屋顶只移除对应格的顶面，墙段和屋顶格仍能单独修复。
