# 整组建造与独立部件损坏

日期：2026-10-06。

## 当前规则

- 建造仍按蓝图中的木地基、围墙、门、屋顶、床分别执行，一次建造生成整组，不逐格重复扣料。各组保留原材料、建设经验和 2 秒施工时间。
- 围墙按原导航边拆成墙段，地基和屋顶按占地格拆分；门与床仍是单件。每段 / 格有独立耐久，受击不影响同组其他部件。小木屋单段墙满耐久为 20，大屋为 30；野猪每击 4 点，分别需要 5 次 / 8 次击破。其他部件沿用既有耐久。
- 只有被破坏的墙段消失并开放对应通路，其他墙段保持阻挡。受损墙与地板显示裂痕，破坏的地板显示裸露地面；屋顶逐格显示缺口。屋顶降低遮挡以便辨认室内地板。
- 每个受损部件有独立修复气泡、订单和预留，可以分别安排与取消。修复材料暂沿用原类别的修复材料，修复一次仅恢复目标部件，耗时仍为 2 秒，不再次发建设经验。
- 整组首次建造保护该组；独立修复只保护正在修复的小部件，其他墙段仍可受击。开工后主角免伤且作业不可中断的规则保持。
- 完整封闭要求每段围墙与门均未破坏；防雨要求屋顶每格均未破坏。损坏地板不额外阻挡角色，地板下的原地面仍可走，避免把人物困住。
- 点击屋内地板与点击普通地面使用同一精确移动流程，仍经门或真实缺口进入。移除完工后的房屋“进入”气泡以及照护面板的“走进木屋”按钮；保留床边休养。

## 状态与实现

`buildingSegments.ts` 从既有图纸派生稳定局部 ID：围墙 `edge0…`，地板 / 屋顶 `tileX-Y`。不修改原图纸组 ID、材料表或配置指纹。改变边顺序或图纸尺寸会改变局部含义，后续必须另做迁移。

多件部件保存 `parts[partId].segments: Record<string, number>`，组上的 `hp` 为最小耐久，仅作兼容汇总；攻击、通路、绘制、修复均读取具体小部件的耐久。禁止通过修改汇总 `hp` 代替修改小部件。

首次建造订单 ID 仍为 `buildingId:partId`；独立修复增加 `segmentId`，ID 为 `buildingId:partId:segmentId`。修复气泡固定在对应墙段中点 / 地板格 / 屋顶格上方，门和床也使用自身场景位置；移除自动防重叠上推，不因其他部件受损、修好或新增气泡而移动。只有尚未建造的整组气泡保留建筑上方排布。物资不足时进入合成，对应修复订单置首高亮。工作位包含目标格 / 墙两侧及原图纸工作位，兼容既有施工位置。

敌人按可达的具体墙段或格选择攻击目标，目标带 `segmentId`；旧敌人目标尚未带 ID 时，按已有站位绑定邻近部件。攻击提交后由 Runtime 更新建筑导航，不由场景动画扣耐久。

## 旧档兼容

- 保持 schema 4。先校验旧数据，再为缺少 `segments` 的多件部件补入各小部件的耐久；每件沿用旧组 HP，已损坏状态不被自动修好。未建造部件全部为 0。
- 旧整组修复订单绑定到该组第一个受损小部件，同步更名订单、工程及原位物资预留；已开工的计时和扣料状态保留，不重复付费。完成后其余受损小部件仍需分别修复。
- 兼容旧 M3 工期迁移、旧区域内容补入和旧精确位置存档。新建小屋及新发现的大屋直接带完整小部件表，重复读取不再改变结构。
- 校验所有小部件 ID、数量、耐久范围、组汇总值、修复归属与预留；错误数据拒绝覆盖，不静默重置建筑或物资。
- 墙体数值后续下调：`migrations/wallDurability.ts` 显式兼容原建筑指纹 `d146dff6` 和原区域内容指纹 `b3fb1516`，小屋围墙由 160 按比例换算为 20，大屋围墙由 320 换算为 30。旧整组与独立墙段均兼容，0 耐久仍为 0；保留订单、预留、施工剩余时间和经验。迁移后写入新指纹，重复读取不再次缩放；未知指纹和超出历史范围的耐久仍拒绝读取。
