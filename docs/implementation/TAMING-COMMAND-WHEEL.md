# 驯服气泡与伙伴指令盘

日期：2026-09-30。当前内容仍是一位小犬伙伴栗栗，未扩展夜袭敌人的可驯服种类。

## 交互

- 白天，野生小犬头顶显示材料气泡：材料图标和已有 / 所需数量，满足条件变绿。沿用 Pixi 场景气泡、缩放、点击及拖动判定。
- 缺料点击打开合成，生成一份持久化驯服订单；重复点击不重复建单。订单统计棋盘及仓库的可用真实物品，排除锁格及其他预留。
- 齐料点击气泡或订单，预留物资并自动前往可达工作位。主角精确到位才扣料，驯服 2 秒后成为伙伴；不会经过格子边缘就提前扣料。
- 前往途中可以点小叉或取消订单，物资在原格释放。途中入夜自动取消前往、保留备料订单；夜间不能开始新驯服，已开始的驯服继续完成。
- 开始后不能取消或移动，主角免伤，饥渴及环境变化照常运行。驯服与施工不可同时安排。驯服不给额外建设经验。
- 点击已拥有伙伴的身体打开中央半透明圆盘：上方休养、左侧驻守、右侧跟随、下方治疗；中央名字与生命。当前模式高亮，受伤 / 恢复中的不可用指令禁用，满生命不浪费药品。缺药时保留圆盘并提示。
- 指令成功后关闭圆盘；点击空白、中心或 Escape 也可关闭。打开圆盘不暂停世界。HUD 爪印仍保留照护、住所及主角床边休养入口；地图动物点击不再进入旧照护页。

## 状态与兼容

- `survival.taming` 保存 `ordered` 与 `job`，作业有 `travel` / `taming`、工作位、真实预留 ID 和剩余时间。
- `GameRuntime` 是扣料、计时、完成的唯一入口；旧 `companion-rescue` 命令也转入计时流程。
- `TAMING_SECONDS = 2` 独立于旧配置内容指纹。继续使用 schema 4，旧档只补缺失的默认驯服状态，不清档、不重新扣料或重置已有伙伴。
- 施工、驯服各自验证预留的归属与数量，存档最终合并所有合法预留做孤立实例检查。禁止同时工作、伪造计时或已拥有伙伴残留订单。
- 前往与进行中的工作均能刷新恢复；后台和剧情暂停计时。主角途中倒下会释放预留，进入原有失败流程；保存失败后重试保存已接受的操作，不再次扣料。

## 验证

- 117 项规则测试通过，包含新增订单去重、仓库预留 / 释放、精确到达扣料、2 秒计时、免伤 / 不可中断、刷新与暂停、入夜、施工互斥、失败救援、旧档校验及保存失败重试。
- 最终生产构建通过。16 项相关移动 Chromium 浏览器流程在修复后分批通过：新增 5 项驯服 / 指令盘流程及 11 项建造、照护、夜袭回归。首轮发现触屏打开圆盘的同次点击会立即触发中央关闭，已改为只接收起始于圆盘内的新手势；原建造刷新测试改为冻结并显式推进时钟，避免错过 2 秒施工窗口。小屏治疗流程检查恢复计时持续和刷新保留，完整 60 秒恢复由规则测试覆盖。
- 已查看头顶气泡、正常圆盘与 320×568 小屏受伤状态截图；隐藏圆盘背后的旧 toast，避免文字叠透。浏览器均使用隔离测试存档，没有修改用户进度；未做真机验收。
