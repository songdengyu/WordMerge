# 装饰拆除与建筑低模

实施日期：2026-10-09。

## 装饰拆除

“装饰 → 已摆放”每件摆件增加“拆除”，同时显示返还的材料名称与数量。“收回”仍返还完整摆件；“拆除”销毁选中的场景实例，不增加摆件库存，返还少量一级棋子。库存中未摆放的物件及人物皮肤不提供拆除。

当前摆件通过商店 / 剧情获得，没有建造材料配方，因此先按材质采用可调整的小额返还表，而不是虚构建造成本。`src/game/decorSalvage.ts` 为规则入口：

| 摆件内部 ID | 返还 |
| --- | --- |
| rug / chair / flowerstand | 木枝（201，一级）×1 |
| table / sofa / bookshelf | 木枝（201，一级）×2 |
| planter / lantern / tea-set | 石镐零件（261，一级）×1 |

目前没有独立石料棋子链，器皿 / 灯具暂返还现有一级工具零件。不会返还金币、钻石或高阶成品；数值属于本轮默认配置，后续可调整。

Runtime 新增 `decor-dismantle` 命令，必须携带具体 `decorationId`。先在克隆生产状态中尝试完整发奖，棋子先入可用棋盘空位，再入仓库；放不下全部奖励则原样拒绝，摆件和棋子均不变。成功后同时提交生产状态和场景实例删除，复用拆除奖励反馈。不存在的 ID 被拒绝；刷新及连续操作不能再次拆同一实例。保留购买 / 剧情来源、原库存和递增实例 ID，不新增存档字段或清档。

## 简单 3D 建筑

`src/scene/buildingModel.ts` 生成真实 XYZ 顶点与多边形面，所有九种图纸共用。底层为有厚度地板、墙体长方体、可绕铰链旋转的门板，以及封闭屋顶楔体。Z 为高度，地板面位于原 Z=0，底座下沉 0.14 格；墙厚 0.13 格、高 29/32 格，门厚 0.09 格、高 24/32 格。XY 仍对应原地图和碰撞规则。

矩形屋顶按屋脊切分，各坡面保留平面；异形屋顶使用到户型外围的距离计算高度，只在实际占格上生成。每个面关联原部件和段 ID，损坏 / 未建造段不生成。相邻实体重复内面成对剔除，损坏后缺口侧面重新露出，避免内部面排序到表面造成色块。原床位继续用上一轮的长椅 Sprite。

`BuildingModelView.ts` 在 CPU 上执行固定正交投影、背面剔除、面深度排序和方向光照，再由 Pixi 绘制。投影公式为 `screenX=32(x-y)`、`screenY=16(x+y)-32z`。这是 XYZ 几何驱动的固定视角低模表现，没有切换到 Three.js、自由 3D 镜头、GPU 深度缓冲或真实动态投影。

场景墙段与人物 / 家具继续独立深度排序。屋顶进屋及摆放时隐藏，门由原距离检测和铰链角度驱动；分段修复和凹口通行保留。小木屋既有木纹、窗饰等叠加细节保留，屋顶改为低模色面。商店图纸卡片、摆放预览也从同一模型生成；预览半透明并保留占地 / 门口标记。

静态模型只在建筑状态或预览改变时生成，门仅在开合状态改变时重绘。模型变更不修改 Runtime 建造命令、图纸配置指纹或存档；已有房屋刷新获得新外观。

## 模型导出

```powershell
node scripts/export-building-models.mjs
```

已生成 `public/assets/survival/models/` 下九套 OBJ 与共享 MTL，可在 Blender 等软件打开。导出为完整房屋、原点、朝向 0、Z 向上，保留段分组；包含封闭门板，不含场景 Sprite、窗饰或动画。运行时直接生成几何，不额外下载这些导出文件。

## 验证

构建通过，保留既有主 JS chunk 超过 500 kB 的警告。27 项规则 / 几何测试通过，覆盖拆除入库与刷新防重、满仓和部分容量不足回滚、建筑分段 / 异形规则、九图纸四向投影、厚度、凹口 / 损坏缺口及 OBJ 导出。

19 项不同浏览器流程最终通过，使用隔离存档：普通屋四向进出、两种异形屋各四向进出、旧档购买 / 完整施工、凹口家具限制 / 损坏刷新、屋顶单段修复、320px 装饰拆除发奖与库存刷新、昼夜火把，以及溪谷 / 林地窄屏场景。首轮拆除断言误匹配了场景奖励与面板提示两个 `status`，限定面板后复测通过；内部面剔除后又复测普通屋和单格屋顶修复。没有将失败断言当成功，也未操作用户存档。

已查看普通屋、L 形屋室内外、凹形损坏屋顶、3D 放置预览与窄屏拆除界面截图。桌面模拟环境短时 179 帧采样平均间隔 41.06 ms、p95 50.10 ms，帧率仍偏低；不宣称真机性能验收。真实手机性能、任意视角透视和长期数值平衡不属于本次已验收内容。
