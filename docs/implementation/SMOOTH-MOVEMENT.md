# 主角、伙伴与敌人的连续移动及平滑寻路

日期：2026-09-30。按用户要求，在原 A* 基础上改进点击落点、路径形状和移动衔接。

2026-10-06 后续修订：伙伴移动复用主角的连续导航；地图只显示目的地，不再绘制主角路径连线和节点。

## 当前行为

- 普通地面点击保留格内坐标，主角能停在点击位置，不再逐格对齐中心。蓝图、装饰和物体交互仍使用原格坐标。
- 无阻挡时直接走直线；否则由八向 A* 找可通行路线，再合并可直达的中间节点。允许斜向，但禁止穿过被障碍或墙边夹住的角。
- 可通行的转角采用短二次曲线采样过渡。整段弯道不满足碰撞检查时保留安全转折，不强行圆滑穿墙。
- 移动速度为每秒 2.5 地图单位，按线段实际长度分配步长；跨过短节点后继续使用本拍剩余距离，不在节点停顿。渲染继续在 50ms 固定模拟步之间插值。
- 途中重新点击，从当前位置重新规划，不先走完原来一格。无效 / 未开放地面点击保留当前行动；点击过于贴近障碍边缘时，将落点收进同格的安全位置。
- 合成、照护和普通面板打开后继续移动；后台及原有暂停条件仍冻结世界。主角必须精确到达工作位，才扣材料并开始不可中断施工。

## 碰撞与范围

`smoothNavigation.ts` 使用沿线网格遍历和扩展矩形相交检查，覆盖地形障碍、地图边界及建筑格边。角色保留 0.15 地图单位的安全半径；只有终点可走并不代表整条直线可走。

主角、伙伴与敌人的八向搜索使用对角线真实代价与八方向启发距离；原 `PathSearch` 默认四向行为保留给建设可达性检查。木门仍按原规则对友方通行、对敌人阻挡。

## 镜头跟随（2026-10-08）

- 恢复跟随 / 切换目标时，镜头从当前视角插值返回移动中的角色。`src/scene/cameraConfig.ts` 的 `CAMERA_CONFIG.followReturnSpeed` 为每秒收敛速率，默认 6，数值越大越快（约 0.5 秒消除 95% 初始偏移）；`settleDistance` 为结束过渡的像素阈值，默认 0.25。采用按帧时长计算的指数衰减，30 / 60fps 一致；单帧最多按 0.05 秒推进，避免后台恢复时跳变。
- 仅衰减返回时的初始视角偏移，目标行走位移照常跟随；返回完成后保持居中，不持续落后于角色。再次拖动会取消返回过渡，重新定位或行走时从新的视角重算；参数仅影响表现，不改变存档。
- 插值修订已通过构建、6 项镜头单元测试及 7 项浏览器流程；覆盖帧率一致性、可调速度、后台大帧、返回过程 / 再次拖动、角色切换和普通拖拽。桌面两项在用户正在使用的 `localhost:5173` 执行，其余在独立移动端测试服务执行。
- 场景默认跟随主角，进入伙伴操控时切换到该伙伴。按模型的帧间插值位置逐帧居中，避免相机按 50ms 模拟步跳动；停止行走后继续保持跟随状态。
- 单指 / 鼠标拖动超过轻点阈值、双指捏合移动或滚轮缩放会暂停跟随；仅轻点按下不打断。暂停跟随不撤销行走，定位主角或重新发出有效行走指令恢复对应目标的跟随。
- 建筑 / 地块定位暂停跟随，保留查看位置；主角开始前往新的施工等工作位时恢复主角跟随。镜头状态仅在 CampScene 保存，不写存档、不改变寻路与资源消耗。
- 相机在角色插值之后、光照及气泡投影之前更新，场景命中、光源与镜头外刷新共同使用更新后的相机。
- 行走命令保存回执恢复跟随前检查相机操作序号，避免延迟回执覆盖之后的手动查看或定位。
- 后续修复：单指拖动时，之前排队的行走指令可能在拖动后才生成新目的地，原先渲染层据此重新开启跟随，导致镜头回弹。手动查看现在同时锁住“新目的地自动跟随”，直到新的地图轻点 / 定位 / 进入伙伴操控解除；不只拦截保存回执。新增真实单指触摸回归，覆盖指令尚未执行时拖动、停留和松手后的镜头保持。
- 本轮构建通过；最终 6 项移动 Chromium 交互流程通过，覆盖主角 / 伙伴跟随、拖动暂停与恢复、角色切换、途中改道和双指捏合。旧改道测试点位命中树冠，改为明确空地并冻结手势间时钟后复测通过；此前同轮另通过精确落点刷新、移动存档续接与动态动物招募 / 镜头外刷新回归。未做真机性能验收。

## 伙伴移动修订（2026-10-06）

- 指定移动、驻守回位、跟随、追敌均复用 `SmoothPathSearch` 与 `walkPath`：直达优先、八向绕行、视线简化、安全拐角圆滑，按实际距离推进。
- 地图轻点保留精确坐标，主角与伙伴共用 `moveTarget` 处理靠近障碍的落点；途中重新点地面从伙伴当前位置改道，不影响主角目的地。伙伴速度仍读取自身配置，目前为每秒 2 地图单位。
- 跟随使用主角精确位置，追敌使用敌人插值位置；进入交战还检查真实距离与敌方墙边通路，避免隔墙开战。
- Runtime 快照携带伙伴上一固定步的位置，Pixi 在渲染帧间插值。主角只显示浅色终点圈；伙伴指定移动时显示绿色终点圈。
- 伙伴存档增加可选 `motion: { version: 1, position }`，保存连续路线和精确目的地。旧 `cell / progress` 档案从原真实位置转换，不跳回格心；后台不补算移动。旧 `rest` 仍迁为原地驻守。
- 伙伴路线按友方门墙与角色半径验证；交战期间冻结的路线先检查世界地形，恢复行走时重新检查当前建筑边界，兼容战斗期间墙体改变。
- 此移动修订已有 143 项规则回归通过，新增伙伴移动测试另行运行 5 项通过，构建通过；覆盖格内落点、等速直线、途中改道、门墙、旧档、刷新和暂停。按随后用户要求未运行游戏或浏览器验证。以下 19 项浏览器结果仅属于 9 月 30 日主角移动版本。

## 敌人移动修订（2026-10-06）

- 灰狼、夜袭野猪与溪谷常驻野猪复用伙伴的连续路线规划和步进函数：直达优先、八向 A*、视线简化、安全圆角及实际距离推进。分别保留配置速度 1.2 / 0.9 地图单位每秒。
- 索敌优先级、视野、决策间隔保持原规则；追击以主角 / 伙伴的精确位置为终点，从敌人当前位置重新规划。破障候选按路线实际长度比较，不能用平滑后的路径点数量代替距离。已到达有效破障点时不重复遍历全部部件，但仍重新判断附近单位和已有缺口。
- 敌人继续受完好墙门阻挡；溪谷野猪的搜索、整段移动与存档校验共用区域限制。主角即时受击及伙伴 2 秒交战机制保持，触发攻击时检查真实距离和中间阻挡；建筑攻击须到达对应工作点。
- 每步检查剩余路线，墙门修复后重新规划；新修复的边如果覆盖单位安全半径，则向单位当前格内退让，避免卡在墙边或穿过新墙。
- Runtime 快照按敌人 ID 记录上一模拟步位置，Pixi 同样插值；正在烟尘 / 胜负动作中的双方保持锁定，其他敌人继续平滑移动。
- 敌人保存可选 `motion.version = 1` 和精确位置；旧整数路线从原 cell / progress 真实位置转换，schema 4 和配置指纹不变。后台暂停、刷新续行，救援保留常驻野猪的精确位置。冻结交战路线仅放宽实际参战双方的动态建筑检查，结束后重新检查。
- 验证：构建、170 项规则测试通过，新增 9 项覆盖两类敌人的斜向等速、实际位置追踪、绕墙、门阻挡、真实攻击距离 / 间隔、旧档 / 暂停 / 刷新、修复墙边退让与溪谷边界。三天供需脚本仍通过，按交战锁定状态等待后再照护；全天 / 三天用例分别允许 15 / 60 秒运行预算，模拟步长和游戏规则不变。
- 8 项相关移动 Chromium 流程通过，涵盖夜袭、伙伴战斗 / 胜负演出、后台 / 刷新、失败救援及区域野猪；首轮战败动作时序用例失败，单独复测通过。未做真机性能验收。

## 手动点击不可达区域（2026-10-09）

- 地图拖动判定独立使用 `CAMERA_CONFIG.dragThreshold = 18` CSS 屏幕像素（原 8）。按下后以起点到当前指针的直线距离判断，严格超过才取消跟随并拖图；阈值内释放仍为点击。进入拖动后保持到手势结束，即使回到起点也不补发点击。双指缩放保持原交互。

- `manualMovePath` 先尝试原直线 / 八向 A* 平滑路线；目标无法抵达时遍历角色当前连通区域，将点击处投影到各格安全内部，选择距离目标最近的可达落点。沿用墙边、地形及角色半径碰撞检查，路线仍做视线简化和安全圆角。
- 水面、障碍、未开放地块、地图外和隔断的陆地都能作为移动意图；角色到安全边缘停止。已在最近边缘时重复点击保持原位；行走中改点立即替换原路线。
- 主角 `move` 与伙伴 `companion-move` 共用此处理。资源点击仍同时显示工具气泡和前往物体旁；找不到相邻工作位时也尝试靠近，不直接拒绝移动。
- 只保存实际可达终点与安全路线，刷新续行无需存档迁移。工作任务、跟随、追敌等仍走原严格寻路，不能靠近施工 / 驯服 / 清理 / 开地工作位就扣料开工。
- 构建和 235 项规则测试通过（本轮未重复长时三天经济模拟）；新增 6 项覆盖水面 / 障碍 / 边界 / 不连通区域、墙阻挡、重复点击、途中改点、保存恢复及伙伴一致性。
- localhost:5173 的 6 项移动 Chromium 浏览器流程通过，覆盖真实水面点击、行走中改道、岸边停止 / 重复点击、刷新续行、格内精确目标、镜头跟随与鼠标 / 触屏拖动。测试使用隔离存档，未修改用户存档；未做真机性能验收。

## 保存兼容

- schema 4、地图 / 物品 / 建筑配置指纹不变。
- 新存档增加 `motion: { version: 1, position }`，`cell` 保存所在格，`progress` 为 0，`route` 保存连续路径点，`destination` 可为格内坐标。
- 校验精确位置与所在格一致，连续路线每段可通行且不穿建筑墙，开工状态必须位于实际工作点。非法坐标、路径与移动版本拒绝覆盖。
- 旧档缺少 `motion` 时按原整数路径验证，恢复 `cell + 首段方向 × progress` 的真实位置后简化剩余路线；不清档、不回退到格子中心，不补算离线行走。
