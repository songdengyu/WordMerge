## 试玩

在工程根目录 `npm run dev`，访问终端地址加 `/?game=survival`。默认 `/` 仍启动继承 Demo。新模式显示“林间营地”，这只是场景称呼，未确定正式游戏名称。

- 轻点空地：四方向寻路；地形、树木、岩石、营火与路标阻挡所在格。
- 单指拖动：查看营地，移动超过 8 CSS 像素后不再触发点击。
- 双指捏合、鼠标滚轮或右侧加减按钮：0.65–1.6 倍缩放；罗盘将镜头移回主角。
- 营地地图：查看一个已开放区域与两个锁定区域，可让角色走回出生点的营火旁。
- 探索指引：普通弹层，角色和时间继续；切后台、页面隐藏或 WebGL 丢失则暂停，恢复不补算离开期间的世界进度。

地图、美术、提示文案是可替换原型。没有合成、生存消耗、正式剧情、建造、伙伴与夜袭；邻区不能解锁。没有存档，刷新重新开始。

## 实施结果

- `GameRuntime` 是新模式唯一逻辑状态源；React 订阅稳定快照，Pixi 不结算游戏结果。
- 50ms 固定逻辑步，普通 UI 100ms 发布；逻辑与渲染插值分离。默认一游戏日 1200 活跃秒，06:00 起步，06:00–19:00 为白天；颜色变化仅为昼夜示意，没有天气与危险效果。
- 暂停原因集合支持叠加；恢复一个原因不清除其他原因。超过 1 秒的卡顿丢弃世界欠账，较短卡顿单帧最多推进 250ms。
- 浏览器生命周期与视图初始化均有清理；StrictMode 重挂载不产生额外时钟或残留画布。
- 16×16 chunk 配置、64×32 等距格；四向 A* 每逻辑步最多处理 96 个节点，预算用尽继续等待，真正无路才报错。边阻挡双向生效；本阶段地图没有可变门墙。
- 途中改道先走完当前边，再接新路线；配置 / 输入不合法不覆盖当前有效路线。
- 地图块与地图实体按视口裁剪；渲染 DPR 上限 2。相机移走不会停止模拟。
- JSON 加载时检查区域 / 元素重复、坐标、地形、出生点和阻挡边；错误可见并可重试。
- 主角 / 场景由 Pixi Graphics 绘制，HUD 用 React / CSS / 内联 SVG，没有新增外部素材依赖。
