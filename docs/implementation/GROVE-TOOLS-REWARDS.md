# 高阶工具、林地地基与拆除奖励表现

2026-10-08。用户要求扩展工具链、给林地大屋初始地基、增加高阶工具拆除的钻石雕像，并展示拆除奖励。

## 内容与数值

| 合成链 | 一级 | 二级 | 三级（新增） | 四级（新增） |
|---|---|---|---|---|
| 斧头 | 斧头零件 251 | 斧头 252 | 钢斧 253 | 精工斧 254 |
| 石镐 | 石镐零件 261 | 石镐 262 | 钢镐 263 | 精工石镐 264 |

两件同级合成下一级，原工具箱产出不变。高阶工具可替代同链低阶工具；优先最低满足等级的可用工具，跳过锁格及预留。地图气泡和合成订单显示实际将使用的工具。清理仍消耗一把，2 秒施工，开工扣各 1 饱食 / 水分、保护主角；点击资源前往与缺料建单规则不变。

静谧林地 `lodge` 发现时已有完整 5×4 地板，直接从围墙开始建造。按原地基经验记录一次 20 建设经验（发现经验的原型处理），不扣材料；不额外增加一栋房屋。其余四组照常建造。

地基旁新增“林地守望雕像”，石质守望兽外形。暂定拆除消耗 **1 把四级精工石镐，奖励 30 钻石**，无金币或材料。这些是本轮实现的初调数值，尚未作长期经济平衡验收。参数在 `economyConfig.ts`。

## 场景与存档

雕像使用 `grove-statue` 固定 ID，坐标存在 `progression.regionContent.statue`。一般在大屋左侧 `(23, 6)`；若旧建筑、角色、工作位或保存的连续路径占用附近空间，则选择邻近空地，留出建筑通道并避开信匣。无合适位置时暂不补入，后续恢复或区域补入时重试。坐标确定后不随角色移动，不因刷新重新选点；拆除记入既有 `economy.removedObjects`，不重生。

工具 CSV、经济配置、区域内容都有显式版本迁移；原地图与房屋定义的指纹保持。兼容上一批内容版本及已有更早迁移链，保留原档，不清档。

- 旧林地未建地基补为完整地基，一次补记 20 经验。
- 已建地基保持各段损伤与经验，不免费修复。
- 尚未开工的地基订单取消、预留原位释放；若正在前往，同时停止该路线。
- 已扣料开工的地基保留剩余工时，正常完成，不补扣或重复经验。
- 旧墙耐久迁移先落到上一版区域配置，再走本轮地基迁移。
- 迁移前验证来源与预留，迁移后按新障碍复查建筑、移动、作业和伙伴数据。

## 掉落表现

Runtime 在拆除奖励结算后发出临时 `LootFeedback`，Pixi `ResourceDrops` 在原物体位置画出金币 / 钻石 / 材料图标、名称与数量，带短暂星光、弹跳与上浮淡出，整体缩放为原来的 75%，约 1.8 个模拟秒后消失（后续表现修订）。相同材料合并计数，数量为 0 的货币不显示。

满仓时货币照常到账，材料显示“×数量 · 待领取”，领取权仍在商店；之后成功领取只显示材料，不重播货币。失败指令、取消、刷新不发新表现记录。动画不发奖、不写存档、不拦截点击，离线或暂停时与世界一起暂停；无障碍文本与场景内容一致。
