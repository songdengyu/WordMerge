# 水域移动与火把熄灭

日期：2026-10-10。

主角可以点击进入已开放水域，也可以走水面到另一岸。水中速度默认陆地的 50%，即每秒 1.25 格；上岸恢复每秒 2.5 格。参数位于 `waterMovement.ts` 的 `WATER_MOVEMENT.speedMultiplier`。

`walkPlayerPath` 将路径按格子交界拆成水 / 陆小段，逐段花费当前固定步的剩余时间；跨岸边、斜线和多个路径点时保持连续，不丢失路程。饱食 / 水分的累计移动扣除继续使用实际走过距离。

`WorldMap.isWalkable / canStep` 增加可选水域通行，默认仍是陆地。`constructionNavigation` 的 `player` 网格允许水域、可过友方门，并与伙伴 / 敌人缓存隔离；碰撞半径、岩石、资源物体、墙体与区域边界继续生效。建筑、装饰、生成怪物仍按原陆地限制。主角在水中可以继续安排陆地施工、清理、驯服和开地，准确抵达工作位后才扣料。伙伴和怪物未扩展水中行为。

随身火把在实际接触水域的模拟步立即熄灭，剩余燃烧时间归零并触发保存。水中点击火把提示先上岸，不消耗木枝；按钮显示“上岸点燃”。离水不自动复燃，重新点燃仍花费两根木枝。场景光圈与手持火焰继续由权威剩余时间派生。固定营火和场景灯不受此机制影响。

主角读档校验使用水陆通行，保留水中连续位置和路线；恢复水中状态时确保火把熄灭。没有改动存档结构和配置指纹，已有陆地存档正常加载，不清档。伙伴位置 / 路线继续严格按陆地校验。
