# 区域边界指示牌

日期：2026-09-30。替代原“营地地图”页的开放列表、地标前往按钮和返营按钮。用户明确要求：**每个未开放地块的四条边各放一块牌子，从主角可达的一侧接近；开放后该地块四块牌子一起消失。** 不新增南 / 西区域，继续使用现有溪谷与林地。

## 交互与作业

- 指示牌在 Pixi 地图容器中绘制，显示“建筑经验”及已有 / 所需数值，随镜头缩放。经验达到门槛且外侧工作位属于可行走的开放地形时变绿；实际点击时进一步检查建筑和完整路线。
- 后续显示规则修订：四边保留候选位置，只有与已解锁地块接壤的一侧显示指示牌；邻接未开放地块或地图外的一侧隐藏。邻接关系随区域开放自动更新，地形障碍仍由原可达性逻辑处理。本次为简单 UI 显隐调整，按用户约定未运行验证，下方验证记录属于此前版本。
- 溪谷要求 30 建设经验，林地要求 70；取消此前剧情前置，不消耗经验，不额外发经验。经验不足或该侧不可达时提示，不能遥控瞬间解锁。
- 点击后主角自动前往对应边的外侧工作位。途中显示取消按钮；精确到达后开始 2 秒作业，显示进度条，期间不可取消且主角免伤。饥渴、天气、其他营地对象仍正常模拟；与建设 / 驯服互斥。
- 完成时只开放一次区域，更新权威地图和寻路，移除该区域全部四个牌子。其他未开放区域仍有自己的四个入口。
- 后台或剧情暂停计时；前往途中倒下清除任务。刷新后恢复移动或剩余作业时间。
- 底部只保留合成入口，设置仍由左上角叶子按钮打开。手记的“前往完成目标”在区域未开放时定位可达指示牌，已开放时引导主角前往地标。

## 实现与兼容

- `src/game/regionUnlock.ts`：由地图块坐标派生四个牌子、外侧工作位、可达性与任务命令。`GameRuntime.ts` 负责移动、保护、倒计时和原子完成，场景不持有权威状态。
- `progression.regionUnlock` 保存区域、方向、工作位、阶段和剩余时间；`progressionValidation.ts` 校验真实边界工作位、经验、互斥任务、移动目标和计时。
- schema 保持 4；旧 M5 剧情配置指纹 `7a73e35c` 显式迁移至当前指纹，缺少任务字段补 `null`。保留原库存、建筑、区域、故事及装扮，不清档。M2 / M3 / M4 迁移继续兼容。
- `BuildingBubbles.ts` 统一绘制和命中检测；四块牌子的无障碍镜像只提供语义与坐标，实际触摸到达画布，拖动或缩放不误触开放。
