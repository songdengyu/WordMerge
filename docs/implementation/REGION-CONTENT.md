# 溪谷野猪与林地大屋地基

日期：2026-09-30。用户要求在溪谷放置几只野猪、林地放置大房子地基，并明确选择“3 只常驻溪谷，主角靠近时攻击”。

## 区域内容

- 溪谷开放后生成 3 只野猪，默认位置 `(4,-12)`、`(7,-10)`、`(3,-7)`；旧建筑占位时选择附近空地。使用现有野猪外观与数值，3 格内发现主角或伙伴后追击，路线限制在溪谷内；脱离接近范围后返回原出生点，不能主动跑去营地夜袭。白天也可以交战。
- 常驻野猪与夜袭单位共享伤害、伙伴指令、血条和掉落，但不计入夜袭 3 个敌人的上限；天亮、时间测试跳转和失败救援不会清除常驻野猪。远处的野猪不阻止营地床边休养。击败后不因刷新重新生成，暂不加入自动复活或驯服。
- 静谧林地开放后出现“林地大屋”固定地基，默认原点 `(25,3)`，占地 5×4；初始为待施工地基轮廓，第一步使用木料×2 建地基。继续通过气泡建墙、门、屋顶、床，所有部件建设 / 修复均为 2 秒。屋顶和定位按实际尺寸绘制 / 居中，围墙和木门接入现有导航、防御、住所系统。
- 固定地基不能收回或从蓝图列表重复放置；不占用玩家原有 16 座可放置建筑的额度。发现时不发经验，实际建成对应部件才获得一次性经验。缺料点击建立合成订单。

大屋材料、耐久和经验属于本轮暂定内容配置，后续可调。它仍使用五种现有建筑部件，不引入新生产链。

## 保存与兼容

- `regionContentConfig.ts` 配置出生点、警戒距离和大屋位置；`regionContent.ts` 在区域开放完成或读入旧进度时填充内容。
- `progression.regionContent` 保存 `version` 与 `initialized`。初始化标记保证旧档补入、刷新、迁移、失败救援不重复生成；敌人的 `residentId` 标识区域来源。
- 基础地图、剧情、原木屋和生存配置指纹保持稳定，schema 仍为 4；区域配置和固定建筑单独计算 `REGION_CONTENT_VERSION` 并校验。旧档缺少字段时补默认值，再根据已开放区域加入内容；已有建设、经验、物品和伙伴不重置。
- 大屋补入会检查地形、已有建筑一格间隔、后续工作位与故事地标，原位置被占用时寻找林地的其他合法位置。若旧地图完全没有合法占地，则暂不放置，也不覆盖现有建筑。
- 存档拒绝无来源 / 越界 / 重复的区域野猪，以及缺失或重复的大屋和不匹配的区域配置版本。
