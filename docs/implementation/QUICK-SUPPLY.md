# 快捷状态补给

更新日期：2026-09-30。

## 当前行为

- 营地、合成页、照护面板的生命 / 饱食 / 水分图标可以直接点击。每次消耗一件实际道具，满值不消耗，缺料仅提示。
- 库存统计棋盘和仓库，排除锁格与工程预留；按恢复量从小到大选择现有补给。没有可用物品时显示该状态最低阶的补给图标。
- 饱食、水分 ≤20，生命 ≤30 时在右上角显示物资角标。生命使用现有低生命预警，饱食与水分在扣血边界预警，实际环境伤害仍按 <20 判定。
- 角标有料时保留正常背景，点击使用；缺料时圆形背景变红、资源图标保留原色，点击打开合成并创建对应补给订单。照护面板会先关闭，再进入合成。
- 同状态最多一张订单，可取消，刷新后保留。备料完成点击订单，消耗一件所需物品并恢复状态，不奖励货币；手动使用该状态的其他补给也会结束订单。
- 没有增加额外背包；每次点击只执行一次 Runtime 命令，原有连续时间、世界暂停与存档故障处理继续生效。

温度当前没有可消费的补给道具。本轮已询问新增暖身 / 降温品、复用现有物资或仅给出环境提示的选择，尚未收到确认。当前温度计点击仅给出住所保温 / 遮蔽降温提示，温度角标与订单未实现。

## 实现与兼容

- `src/game/quickSupply.ts`：补给选择、危险阈值、快捷使用与订单命令。
- `src/game/inventory.ts`：复用 `item-use` 扣除真实实例，同时结束同状态的订单。
- `src/game/GameRuntime.ts`：命令串行执行、同步状态、提交保存。
- `src/features/survival/StatusIcons.tsx`：图标按钮和资源角标；`ProductionScreen.tsx` 展示可使用 / 取消的补给订单。
- `production.supplyOrders` 为增加的保存字段。未变更 schema 4、物品 CSV 或配置指纹；旧档缺少列表时补 `[]`。校验重复状态、未知状态及道具与效果不匹配，错误存档按现有恢复流程处理。
