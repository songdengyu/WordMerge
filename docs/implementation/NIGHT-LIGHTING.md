# 深夜照明与随身火把

2026-10-08。用户要求保留白天 / 黄昏基调，加强接近深夜时的黑暗，让火把、灯、营火照亮地图；火把常驻定位按钮右侧，每次消耗两根木枝，燃烧一段时间后熄灭。

## 当前行为

- 白天、黄昏主要色调与原参数保持。19:00 后持续变暗，22:00 无光处已很暗，23:00—04:30 无光处不显示地图，黎明逐渐亮起。界面按钮、状态和提示不受场景黑暗遮挡。
- 定位按钮右侧新增火把按钮。未点亮时显示“木枝×2”，点亮后显示燃烧倒计时和剩余环。缺料提示准备木枝；不自动生成专门订单。
- 每次点燃消耗棋盘 / 仓库中两根可用一级木枝（201），排除锁格和预留。燃烧中重复点击只提示剩余时间，不再扣料，也不重置计时。
- 初调燃烧 **60 个在线模拟秒**。主角手中显示火焰，光源跟随连续移动和镜头缩放；最后 2 秒光照渐弱，到时自动熄灭，可再次付费点燃。
- 点燃是即时补给操作，不打断行走、施工或操控伙伴，不额外扣精力 / 饱食 / 水分；火把始终由主角携带。
- 合成和普通面板期间继续燃烧；后台、离线、剧情、失败和保存故障等世界暂停期间停止计时。剩余时间存档，刷新不重新扣料、不补满时长。测试跳时和救援跳到黎明不补扣跳过的燃烧时间。
- 场景既有营火改为有火焰的固定光源，已摆放的暖光提灯提供固定光照；本轮暂不消耗燃料。拆除营火、收回 / 移动提灯会同步移除 / 移动光源。
- 光源可叠加，雨天仍照明。当前只改变可视范围，不新增驱怪、温度加成或黑暗伤害；原敌人机制保持。

## 实现入口

- `src/game/lighting.ts`：木枝需求、火把时长与光照半径。半径是地图投影世界单位，火把 150、提灯 180、营火 210，统一随镜头缩放。
- `GameRuntime.ts`：`torch-light` 命令原子扣料，固定模拟步进消耗 `survival.torchRemaining`；保存重试不会重放点燃命令。
- `survivalValidation.ts`：校验剩余时间为有限的 0～60；旧 schema 4 字段缺失视为未点燃，不改变配置指纹、不清档。
- `TorchButton.tsx`：只发送命令，绘制燃烧环、秒数与木枝提示，React 不自行扣料或计时。
- `environment.ts`：平滑插值的深夜黑暗曲线。
- `Atmosphere.ts`：半分辨率 Canvas 软遮罩生成 Pixi 纹理，用透明渐变光圈揭开黑暗，多个光圈合并；静止镜头约 30Hz 更新，镜头 / 光源移动及时更新，重用纹理。天气也在黑暗层之下，暖色微光叠在照亮范围内。
- `CampScene.ts`：主角手持火焰、营火外观与实时光源坐标；DOM 无障碍气泡维持原规则，地图灯光纯表现。当前为径向光照，未实现墙体 / 树木投影遮光。
