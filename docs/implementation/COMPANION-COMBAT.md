# 伙伴战斗：2 秒烟尘与一次性结算

日期：2026-10-06。替换 M4 的伙伴即时互击，保留既有索敌、寻路、驻守 / 跟随 / 指定目标，以及主角和建筑的即时受击。

## 游戏行为

- 伙伴或敌人主动靠近均可触发。双方已有交战目标关系，处于同格或相邻可通行格，并且实际插值位置在近战距离内才开打；墙和关闭的敌方门通路仍阻挡交战。
- 一次锁定一对单位。双方模型、名字和血条隐藏，在两者之间播放地图内的扬尘、旋转烟团、冲击线与飞散颗粒，持续 **2 秒世界时间**。
- 开始时用双方当前生命、攻击力、攻击间隔及剩余攻击冷却，沿虚拟时间线一次算到首次死亡。同一时刻的攻击同时生效，允许双方同时倒下；不再逐拍在真实世界扣除这对单位的生命。
- 烟尘期间双方保持原位置和生命，不能移动、治疗、被另一敌人选中或再接指令。其他敌人仍按原规则攻击主角和建筑，主角照常行动、受击和使用补给。
- 满 2 秒原子提交双方剩余生命与一次金币奖励。接着播放 1 秒胜负动作：胜方跳跃庆祝，败方倾倒；死亡敌人在动作后淡出，伙伴战败保留受伤状态，按原流程治疗。双方同时倒下时都播放倒地动作。
- 胜负动作结束后存活者恢复原有行为，指令和治疗重新可用。后续已移除主动休养回血，改为指定移动；移动途中被拦截时仍会交战，胜利后继续前往目的地。

## 边界与存档

- `survival.duel` 保存 `fighting` / `result` 阶段、剩余时长、交战起始快照和确定的结果。开打、结算、结束动作均触发关键保存；表现不通过动画回调扣血或发奖。
- schema 4 及现有配置指纹保持兼容，旧档缺少 `duel` 时补 `null`。加载时重算校验结果，并检查参与者身份、冻结位置、当前血量、计时和已删除的败方，异常数据不覆盖原档。
- 刷新从当前阶段继续；后台、剧情和保存故障暂停演出，合成与照护界面继续世界。
- 天亮立即撤离未交战的夜袭敌人；已锁定的一对完成结算与动作，存活的夜袭敌人随后撤离。常驻野猪仍保留。测试跳时只改日历，不跳过战斗计时。
- 主角倒下仍是唯一失败条件，失败时交战暂停。接受救援会先把尚未提交的战斗结果结算一次，再按原规则回营地，保留伙伴伤势；不通过救援重置战斗代价，也不重复奖励。结果阶段无需再次结算。

## 代码入口

| 文件 | 职责 |
|---|---|
| `src/game/companionCombat.ts` | 虚拟攻击时间线、2 秒烟尘 / 1 秒动作参数、持久化阶段类型 |
| `src/game/survival.ts` | 接触开战、双方锁定、结算、命令限制、天亮与救援 |
| `src/game/survivalValidation.ts`、`saveData.ts` | 状态交叉校验和旧档默认值 |
| `src/scene/SurvivalActors.ts` | Pixi 烟尘、庆祝、倒地与败方临时渲染快照 |
| `src/scene/CampScene.ts` | 不命中隐藏 / 演出中的动物，保留地图交互 |
| `CompanionWheel.tsx`、`CampCare.tsx` | 战斗期间的指令禁用 |

当前数值未调整。2 秒只是表现时长：例如满血栗栗与满血灰狼、均无剩余冷却时，虚拟战斗持续 4 秒，栗栗剩余 174 生命、灰狼归零，真实演出 2 秒后提交。
