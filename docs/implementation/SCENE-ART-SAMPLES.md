# 首轮立体素材样板

实施日期：2026-10-09。

## 已交付范围

沿用 React、Pixi、固定等距镜头与现有玩法。普通树木、藤编单椅（`chair`）、野花盆栽（`planter`）使用透明 PNG；基础小木屋（`cabin`）使用木墙、木地板与青绿瓦片贴图。建筑仍可四向旋转，家具沿用固定朝向。其他房屋、角色、棋子和 UI 布局保持本轮前的实现。

本轮只改变表现，不修改 Runtime 命令、经济参数、建筑配置指纹或存档结构。已有营地刷新即可使用新外观，不清档、不重建、不补发奖励。

## 接入约定

- `sceneArtCatalog.ts` 统一 URL、原始尺寸、显示高度、脚底锚点、点击范围及气泡高度；资源路径兼容 Vite BASE_URL。树高基准 108、椅子 40、盆栽 46 场景单位，宽按图片比例计算。
- `SceneArt.ts` 单次加载并缓存共享纹理；逐项失败可回退原矢量绘制。异步加载不直接操作场景，`CampScene` 等待后检查销毁状态。纹理跨场景复用，不随对象销毁重复加载。
- 普通树由对象 ID 产生稳定的统一缩放和轻微色调变化，脚底落点不变。点击额外检查图片 alpha，透明角落和很淡的落地阴影不会截获点击；材料气泡使用同一份外观尺度。
- 家具与预览共用 `makeDecoration`，放入角色深度层，继续受前景墙遮挡。预览仅在位置、库存实例或建筑状态变化时重建。商店和装饰收藏通过 `ContentArt` 引用相同 PNG，失败时显示原图标。
- 小木屋的地板、墙、屋顶和门保留原投影多边形。`texturedSurface` 用仿射矩阵将纹理坐标映射到投影面，由 Pixi Graphics 生成纹理网格。地板及每个屋顶翼面共用 UV 坐标框，不在每格重置纹理。
- 仍按原格 / 墙段耐久绘制，破坏段是真实缺口；裂纹、边框、窗饰和床保留。门材质跟随铰链端点动画，屋顶进屋 / 摆放时隐藏。昼夜、雨与火把继续覆盖全场景，没有新增动态投影。

## 体积与性能

六张 PNG 共 **348,824 字节（约 340.65 KiB）**；按 RGBA 展开为 **1,409,024 字节（约 1.34 MiB）**，不含 GPU 副本、mipmap、点击遮罩和引擎开销。

桌面 Chromium 模拟 iPhone 13（设备比例 3，场景渲染分辨率上限 2），同一小木屋内含两件家具、缩放 1.6，分别采集 179 个 requestAnimationFrame 间隔：

| 场景 | 平均间隔 | p95 | 平均间隔折算帧率 |
| --- | --- | --- | --- |
| 新图片 / 材质 | 43.48 ms | 50.10 ms | 约 23 FPS |
| 矢量回退 | 48.69 ms | 66.70 ms | 约 20.5 FPS |

这是分开执行的短时样本，不是严格性能基准，不能推断图片带来了性能提升。本次未见明确的新增性能负担，但两个样本帧时间均偏高；没有达到流畅性验收结论。真机长时运行、低端手机及资源继续扩展后的性能仍待专项验收。
