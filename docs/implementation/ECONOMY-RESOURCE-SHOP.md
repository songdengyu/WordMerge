# 经济、资源清理与商店

更新：2026-10-06。已实现于 `?game=survival`。货币奖励、售价及巡逻距离为本轮可调原型参数，尚未经长期经济平衡验收。

## 玩家流程

- 原“体力”统一显示为“精力”；自然恢复上限 100、道具可突破上限的规则不变。内部 `stamina` 字段保留，兼容旧存档。
- 地图和合成页显示金币、钻石。使用已有 `production.inventory.gold/gems`，不另开货币账户，也不重置旧余额；新档沿用 0 金币、100 钻石。
- 点击已开放地图的树木、石头、旧营火或路标，出现场景材料气泡；足料变绿，缺料点击创建对应合成订单并打开合成页。清理订单沿用置顶、绿色边框、任务类型角标。
- 先在地图右下角的商店免费领取一次工具箱，放入棋盘。每次生产消耗 1 精力，等概率产出斧头零件或石镐零件；两个相同零件二合成工具。
- 足料点击气泡，预留一件工具并前往相邻可达工作位；精确到达后才消耗工具、开始 2 秒作业。途中可取消并释放工具；开工不可打断、主角免伤，与施工、驯服、区域开放互斥。
- 完成后物体消失，通行与建造占用同步释放，货币和材料一次发放。棋盘、仓库均满时先结算货币，材料领取权保存在商店；整理后可领取，不生成额外背包、不重复发币。
- 商店提供工具、图纸、装饰、衣裳分类。购买图纸永久解锁放置权限，仍需材料施工；装饰沿用完工地板摆放；衣裳可直接换装。已拥有商品不能重复扣费，剧情后续奖励同款收藏不会重复添加。

## 生存与巡逻

- 建造、修复、驯服、开放地块、清理资源，每次进入开工阶段扣 1 饱食度和 1 水分。创建订单、取消前往不扣此项消耗；这些行为不额外扣精力。
- 主角实际行走距离累计每满 10 个地图单位扣 1 饱食度和 1 水分，余数保存。斜线、平滑拐弯按实际长度计算，不按点击次数或路径节点数计算；救援传送、伙伴及敌人移动不计入。
- 保留既有随时间发生的饥渴下降，两种消耗叠加；低于预警线仍走原有持续伤害规则。
- 区域常驻野猪在无目标时绕出生点的 2 格范围巡逻，到点停 2 秒；优先原有索敌和追击，追击不离开所属区域。回到巡逻区域后继续巡逻，不更改夜袭敌人的行为。

## 权威状态与兼容

- `economy.ts` 处理订单、预留、购买及领取；`GameRuntime.ts` 推进移动、清理、消耗与完工结算；`economyValidation.ts` 验证购买归属、工作位、计时、预留、移除记录。React 和 Pixi 不扣料、不发奖。
- `RuntimeData.economy` 保存版本、已移除物体、清理订单和作业、购买记录、待领材料、累计步行余数。schema 仍为 4；旧档缺少经济字段时补默认值，不赠工具、不修改旧余额。
- 清理移除通过派生 `WorldMap` 实现；基础地图配置与指纹不改。先派生清理后的地图，再验证存档角色位置、路线及建筑，允许站在已清理的位置和在原物体处建设。
- 显式迁移新增工具前的物品指纹 `e98b4c81` / `9da8a62d`，并识别本版目录等价换行的 `6e361e33` / `726dea98` / `30008215`；不放宽未知配置。原有墙耐久、M3 工期、驯服和 M4/M5 迁移链保留。
- 商店新蓝图由独立经济指纹覆盖，原 `BUILDING_VERSION` 与 `REGION_CONTENT_VERSION` 保持原义。价格、奖励或商店蓝图改变时需同步考虑经济版本迁移。
- 区域敌人增加可选 `patrol` 进度，旧档在首次模拟时补入；沿用平滑寻路、区域边界和位置插值。
