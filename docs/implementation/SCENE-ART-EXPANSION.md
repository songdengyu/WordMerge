## 表现与兼容

所有九类家具的场景、预览、商店与收藏共用素材目录；地毯仍位于地面层，其他家具仍与人物和墙段排序。长椅使用原床位，奇数朝向镜像适配，保持小于原格子的落地范围；损坏变暗，摧毁后消失，修复气泡随长椅高度定位。固定立灯光源提升至灯头附近，营火继续发光。

所有地图静态物件共用图片尺寸 / 脚底 / 气泡参数与 alpha 点击检查，避免透明角落截获点击。原占地和工具要求不变；棕榈仍使用斧头，喷泉仍用四级石镐拆除并发原奖励。加载失败保留各自原绘制，素材自带阴影不叠加旧阴影。

`contentPresentation.ts` 维护显示别名与派生 UI 目录，应用于商店、收藏、摆放提示、任务、剧情和气泡。原经济、建筑及剧情配置保持不变，避免仅改名字导致指纹不兼容。不要把显示目录用于 Runtime 校验或存档；`bed` 仍为建造 / 修复 / 休养的内部 ID，已拥有的物件、数量、价格、进度不改变，不清档。
