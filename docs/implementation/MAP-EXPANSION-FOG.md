## 表现

`LockedRegionFog.ts` 绘制不透明淡灰绿底、层叠浅奶油云团及小幅云边。云团使用世界坐标固定采样，相邻未开放区域花纹连续，地形和资源不透出；指示牌与角色在上层，云雾不处理输入。未开放底色与云底一致，避免缓存遮罩的抗锯齿边露出深色接缝。

云雾按地块一次生成并缓存为半分辨率纹理，随地图缩放、地块裁剪和昼夜光照；没有逐帧重画、粒子或大面积模糊。开放地块后原地图重建会销毁对应云层与缓存。云雾当前静态显示，解锁完成立即消失，未加入淡出动画。
