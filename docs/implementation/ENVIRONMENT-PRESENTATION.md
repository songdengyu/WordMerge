# 日夜图标、天气表现与测试切换

日期：2026-09-30。按用户要求，在 M5 基础上替换数字时钟、增加昼夜 / 天气表现和预设测试按钮。既有日长、生存规则、合成表与存档版本不变。

## 展示与操作

- 地图右上角改为太阳 / 月亮、半圆轨迹和进度光点，保留第几天与时段名称。白天显示太阳、夜间显示月亮，与原有 06:00 / 19:00 的玩法边界一致。工坊使用紧凑版图标，营地危险条显示时段，移除原数字时钟和天亮倒计时。
- 黎明为微亮暖金，正午明亮，黄昏橘黄，夜晚整体冷蓝变暗；关键光照点之间使用平滑插值，午夜首尾衔接。夜间标题改为浅色，操作 UI 保持清楚可读。
- 晴：日间柔和光束与漂浮微粒，夜间微弱萤光；多云：偏冷光照与缓慢移动的柔边云影；雨：更暗的蓝灰光照、云影、斜雨线和扩散涟漪。
- 营火与已摆放提灯周围在暗处有暖光。此为视觉光晕，不提供新增保温或战斗属性。
- 测试入口现统一为地图上的“测试”按钮。一级面板选择“时间与天气”，进入二级面板后可选择六个时段及晴 / 多云 / 雨；另有“状态增减”和“删”。面板不暂停世界；关闭后继续观察地图。保留到后续移除调试入口时统一处理。

## 测试切换的边界

- 修改实际世界状态并沿用自动保存，刷新保留；不是只给地图套一个临时滤镜。当前 schema 4、内容指纹和旧档迁移不变，无需清档。
- 时间跳到下一次对应预设，不回拨世界日历；若目标时段已过去，会进入次日。模拟只推进正常的一拍，不补算跳过的饥渴、环境伤害、战斗、伙伴休养或施工，也不补发体力。
- 跳到白天立即撤掉敌人，不产生击败奖励；跳到夜间重新设置首个敌人补充倒计时（15 秒）。已有建筑、库存、队友伤势和作业保留，正在施工仍按剩余模拟时间完成。
- 测试跳到黎明不写入“自然迎来清晨”的剧情条件；之后自然跨越黎明仍正常记录。天气测试只改当前天气，温度继续逐渐变化；预告保留，下一次自然黎明照常切换天气。测试跳时本身保持当前天气。
- 剧情、后台、失败或存档故障暂停时拒绝测试命令；失败仍按原救援流程处理。没有新增独立计时器或页面直接改状态的入口。

## 实现与验证

- `src/game/environment.ts`：阶段、光照曲线和测试切换。
- `src/features/survival/DayCycle.tsx`：日月图标与进度；`TestControls.tsx`：统一测试入口、两级面板及测试按钮。
- `src/scene/Atmosphere.ts`：全图光照、天气、暖光；使用简单 Graphics，雨粒子数量最多 90，不引入额外贴图或全屏模糊滤镜。
- `GameRuntime` 统一提交测试命令及检查点，`CampScene` 在原渲染循环绘制；旧 `SurvivalActors` 中的简易雨线移入天气表现层。

规则测试覆盖昼夜边界、跨午夜进度、光照连续性、跳入真实夜袭、白天撤敌且不发奖、跳时不完成工程 / 不写剧情黎明、天气渐变 / 保存 / 自然黎明恢复，以及暂停和非法预设拒绝。浏览器检查真实按钮、六时段与三天气截图、刷新恢复、320×568 操作可达和合成棋盘尺寸稳定；原时间推进测试改读只读分钟诊断属性，避免把时段文字不变误判为暂停。

本轮验证：`npm test` 的 9 个文件、94 项通过；`npm run build` 通过；环境、地图、合成、夜袭和剧情相关的 28 项浏览器流程全部通过。已人工查看六时段 / 三天气场景以及小屏测试面板截图，确认夜色、暖色与降雨差异及按钮可达。这些验证为桌面移动浏览器模拟，不构成手机真机性能验收。

## 状态栏视觉修订

同日按用户反馈简化状态栏：天气小图标移至日月图标右上角，移除状态条底框、标签与数字。营地图标使用 32×34px SVG，红心表示生命、胃表示饱食、蓝水滴表示水分；内部填充高度随属性变化，值不高于 5 时显示空心彩色描边。温度计外框和刻度为 1px 细白线，内部填充由下到上蓝—绿—红渐变，液柱随体感温度升降。按后续反馈去掉各图标额外的浅色外沿及伙伴、天气图标的浅色光晕。显示阈值不改变实际属性或伤害规则。

`StatusIcons.tsx` 统一营地、照护和工坊图形，使用独立裁剪 / 渐变 ID；精确数值保留在无障碍标签及只读诊断属性。伙伴入口以爪印和状态点表示，仍打开原照护界面。工坊使用紧凑图标并调整间距，保留既有棋盘尺寸稳定修复。

本次视觉修订单独验证：`npm run build` 通过；满值、半满、低值雨夜、高温四组隔离存档检查通过，覆盖透明底框、无可见状态文字、填充比例、天气位置、照护入口、SVG ID 和页面错误，并已查看截图；合成、夜袭、环境相关 15 项移动 Chromium 浏览器回归全部通过。未改 Runtime、配置或存档结构，无需清档。
