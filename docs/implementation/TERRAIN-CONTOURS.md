# 地形交界圆角

2026-10-09 已实现。仅改变 Pixi 地面表现，不修改地图配置、碰撞、寻路、建造占格或存档指纹。

- `terrainContours.ts` 读取顶点周围四格。当前道路、水岸和岩地统一使用 0.495 格的大圆角，接近逐格轮廓不重叠的上限；`TerrainArt.ts` 使用三次贝塞尔近似四分之一圆弧，端点与连接边相切，岩地不再使用斜切硬角。
- 内凹与外凸角共享相同规则；填色楔形与边线使用同一曲线。直边裁到曲线切点，内部相邻同材质不描边。对角相接的同材质按固定优先级分开修圆；不同材质对角尖端可分别退入共同的底色。无法安全修圆的多材质交汇保留共同顶点。
- 草地侧稀疏增加草叶 / 小石子。长边由两段三次贝塞尔曲线形成不规则凹凸，方向、幅度和峰值位置按坐标固定生成，刷新不改变；水岸 / 道路 / 岩地的最大偏移为 0.14 / 0.11 / 0.08 格，短边按长度缩小。填色与边线共用曲线，不引入逐帧随机、模糊或粒子。
- 跨地块读取真实邻居；未开放或地图外的边缘不做圆角，不泄露未开放地形。每条交界由西 / 北侧格子唯一绘制。
- `CampScene` 按全部地块底色 → 全部转角填色 → 全部边线的顺序绘制，避免后画的邻块盖掉接缝。附加层同样参加原地块可见性裁剪，边界留 8px 余量。只随原地图重建时机刷新，不新增帧循环。

首轮验证：生产构建通过（保留原主包超过 500 kB 提示）；4 项轮廓测试通过，覆盖内凹窄水湾、单格轮廓、对角 / 多材质交汇、跨地块与锁定边界。隔离浏览器流程检查溪谷、林地在 320px 窄屏的正午 / 黄昏 / 深夜 / 火把。已查看初始营地与无物件遮挡的实际地形绘制截图；实际 localhost:5173 页面加载无脚本错误。未做真机性能验收，不改用户存档。

第三轮最大圆角：半径统一增至 0.495 格，并将斜切 / 二次曲线改为圆弧。同步更新原测试的半径上限与岩地圆角预期；按简单外观调整约定，本轮未运行构建、测试或浏览器验证，前两轮结果不作为本轮验证结果。
