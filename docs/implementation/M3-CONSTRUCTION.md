# M3：从图纸到林间小屋

日期：2026-09-30。对应用户“继续下一阶段”。本阶段在 M2 的统一物品与存档上接通完整建造流程，入口仍为 `/?game=survival`。

同日交互修订：按用户要求移除部件材料详情子界面，改用地图气泡；建造与修复统一 2 秒。

## 试玩流程

1. 点击地图左侧“营地建设 → 放置图纸”。轻点地图选址，可以旋转；浅黄色预览表示可放置，红色表示不合法，白色圆点标记门口。
2. 确认后在木屋上方直接显示部件气泡及材料。缺料时保持普通颜色，点击去合成；初始两根木枝合成一块木板即可准备好地基。
3. 材料齐全的气泡变绿，点击直接自动前往，开工后 2 秒完成。工坊也保留工程订单领取入口，统计棋盘与仓库。
4. 开工后可继续合成、吃喝；地图及工坊显示施工保护与剩余秒数。后台暂停施工，刷新恢复。
5. 继续点击木墙、门、屋顶和床铺的气泡完成建设。前置未完成的部件暂不显示；气泡随镜头移动，已安排的工程在气泡中显示状态和开工前取消入口。整屋建成后点击完成气泡进入木屋。

## 当前实现

- 一种 3×2 木屋蓝图，四个朝向，五个部件。新游戏和 M2 迁移玩家均获得蓝图使用权，不消耗图纸次数。每片营地原型最多放置 16 栋。
- 检查开放地形、静态物体、重叠及建筑间一格通道；模拟所有图纸建成后的友方路径，检查工作位和回营通道，避免建成后封死主角。
- 图纸可以在未建设、没有预留作业时收回重放。已建部件暂不开放拆除，避免通过拆建重复获得经验。
- 同一部件只创建一张稳定 ID 的工程订单。前置部件须先建成；订单与 UI 展示无关，重开页面不会重复生成。
- 领取时按需求匹配具体物品实例，在棋盘或仓库原格标记预留。预留实例不能移动、合成、使用、丢弃或被其他委托交付。重复领取原子拒绝。
- 一个主角作业队列；开工前可取消，无法到达或目标失效也释放预留。释放不需要空仓位，因为物品从未离开原格。
- 到达合法工作位后，同一逻辑步骤内扣除预留物品并进入保护状态。开始、结束和领取均请求立即检查点。
- 开工不可中断，移动和取消命令拒绝；其他库存操作继续可用。主角和当前施工 / 修复部件免伤，其他部件正常承伤，不记录延迟补伤。
- 完工恢复部件耐久，首次建设一次性发经验。满耐久修复不生成订单，重复修复不再发经验。
- 墙与门通过格边阻挡，不占整块地面；友方可以穿门，敌方导航被完好门阻挡。破损至 0 耐久的部件开放通路，修复完成才恢复阻挡。屋顶和床铺不阻挡地面。
- “营地建设”只用于选图纸和定位已有建筑；地图气泡显示部件材料、就绪、施工或修复状态，地图底部显示建设经验。屋顶、床铺对温度和休养的实际效果待 M4 接入。
- 气泡外观按用户修订为 60px 圆形，中心材料图标、下方已有 / 所需数量，多个材料 / 部件并排显示；不展示建筑名、部件名、完成数量和操作说明。材料齐备变绿，施工用圆环显示进度，预留后的材料数保持齐备，取消 / 收回仅保留小叉号，完工用房屋图标。操作语义保留在无障碍标签中。

## 存档格式与迁移

当前 `schemaVersion = 2`，配置版本为 `m3-地图指纹-生产指纹-建筑指纹`。数据库名称及 IndexedDB 版本保持不变，仍使用一个事务保存当前快照、上一有效快照和 revision。

- 仅迁移 schema 1 且地图 / 生产指纹与 M2 一致的文件；保留完整物品、奖励记录、随机状态、体力溢出、世界时间、角色路径与移动进度。
- 迁移初始化空建筑、空工程、0 建设经验和一份木屋蓝图使用权；以后按 schema 2 读取，不能重复授予或重置建设。
- 旧 M3 建筑指纹 `6f54c437` 有独立时长迁移：先按原工期校验，已开工任务按剩余比例折算到 2 秒，再写入新配置指纹。已建部件、预留、库存、经验和排队保持不变，不重复扣料或发奖；重复加载不再次缩短工期。
- 导入、启动、损坏备份恢复走同一个迁移与校验入口。未知版本 / 配置继续拒绝覆盖原档。
- 校验建筑位置 / 部件依赖、经验总和、作业单一执行、计时、原位预留一一对应及路径不能穿墙。施工档不得同时存在未消费的预留物品。
- 自动前往、排队、已开工均可恢复；离线不补施工时长。保存失败与多页面竞争沿用 M2 的暂停 / 恢复规则。

## 临时清档入口（2026-09-30）

营地地图左上角体力下方新增临时“删”按钮（清除所有数据）。点击确认后，停止当前运行与保存队列，清除本机新游戏的全部进度及自动备份，再刷新回初始营地；取消不会清档。保存失败与启动存档损坏页面也提供该入口，清除失败显示重试 / 重新载入。

清理仅作用于 `wordmerge-survival` 的快照存储，不清除其他站点数据或已下载的 JSON 备份。清空与更新 `generation` 在同一事务提交；该标记不含游戏进度，只用于防止其他旧标签页在新游戏 revision 重复时写回旧档。原有存档无需迁移，未主动确认清除时保留当前进度。

新增规则覆盖当前 / 备份清理、损坏数据清理、事务失败回滚、待保存队列和旧标签页；浏览器覆盖取消、完整重置后刷新、另一标签页、清除失败重试及启动损坏恢复。
