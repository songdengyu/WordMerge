# Titan Fantasy Art Pack

Original SVG art created for this project in a western cartoon fantasy style with bold outlines and simple color blocks.

## Sprite sheets

- `heroes.svg`: `champion`, `sword`, `archer`, `mage`, `knight`, `rogue`, `priest`
- `monsters.svg`: ten normal monsters and five bosses
- `weapons.svg`: six weapon IDs
- `ui.svg`: navigation, system, currency, crafting, and armor icons
- `battle-background.svg`: layered-looking 1080 x 1248 battle scene
- `platform.svg`: horizontally scalable hero platform

Use a symbol with `<svg viewBox="..."><use href="/assets/fantasy-pack/heroes.svg#champion" /></svg>`.
All files are editable vectors and contain no third-party assets.
