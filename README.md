# 点杀泰坦 Web Demo

Tap Titans 风格的 Web 放置点击游戏 Demo。

## 功能

- 点击怪物造成伤害
- 英雄上阵/下阵，自动 DPS 输出
- 关卡进度 0/10 ~ 10/10，第 10 只后出现 Boss
- Boss 30 秒限时，失败可继续刷怪后手动重试
- 击杀获得金币

## 运行

需要 Node.js 18+。

```bash
npm install
npm run dev
```

浏览器打开终端显示的本地地址（默认 http://localhost:5173）。

## 构建

```bash
npm run build
npm run preview
```
